```bash
npm install   # 若报 npm cache 权限错误：npm install --cache /tmp/npm-cache-yuanhub
npm run dev   # http://localhost:5173
npm run build # 产物输出到 dist/
```

### API 地址配置

在工作区根目录运行 `./dev.sh` 时，前端默认将同源 API 请求代理到本机 `http://127.0.0.1:8080`，后端默认使用 `local` profile 连接本机 MongoDB 和 Redis。本地 `.env` 保持 `VITE_API_BASE=`；需要覆盖代理目标时设置 `YUANHUB_DEV_API_TARGET`。构建部署时可按环境设置 `VITE_API_BASE`。

```dotenv
VITE_API_BASE=
YUANHUB_DEV_API_TARGET=http://127.0.0.1:8080
```

`.env` 已加入 Git 忽略规则，真实地址不应写回源码或提交到仓库。

教程当前默认软隐藏；本地显式开启方法与恢复检查见 [教程维护说明](docs/tutorials.md)。

完整前后端接口契约见 [`docs/api-contract.md`](docs/api-contract.md)。公共关卡读取使用 `/v1/level/catalog`，
关卡管理页使用 `/v1/admin/level-catalog/**`，后者需要登录 JWT 与 `level_catalog:write`。

### 配队与操作图

从桌面侧栏或手机目录的「玩家工具 → 配队与操作图」进入 `/tools/battle-images`。无需登录、创建作业或开启作业系统也可手动编辑。填写标题、游戏和可选署名，在「配队表」中选填五槽位密探、生命、攻击、等级、修为、化极/觉醒、携带/必须/禁用命盘及星石；未知值留空，出图显示为 `—`。公共图鉴按游戏提供名称、别名和命盘词条，已知密探保存稳定 ID 并使用本地立绘，仍可手填自定义名称；图鉴读取失败时保留本地名称目录及手填能力，可重试。

登录后复用全站游戏账号选择器，游戏跟随所选账号并只读展示；游客仍可选择游戏。点击「从我的密探带入」读取账号数据后，点击表头「选择密探／更换」，在表下搜索名字或别名、切换「全部密探／我的密探」并点选候选，即可带入该密探已保存的练度、两套实际命盘与星石配装；账号候选优先排列，自定义名称使用独立确认按钮；未读取或没有该密探数据时继续手填。已有密探再次选择同名或别名不覆盖编辑；需要恢复账号快照时点击「重新带入账号配置」并确认替换该槽位的练度、命盘、要求与星石。第一套命盘默认填入携带命盘，两套组合平铺单选，切换须确认，取消保留原组合与词条，必须／禁用要求不随组合切换清空。养成目标盘不会当作实际命盘导入。图鉴词条可分别添加到携带、必须或禁用命盘。星石优先按账号装备实例关联背包，显示主辅星、品质、等级和突破；无实例配装的密探兼容旧档案星石，明确空配装不回退旧记录。账号、游戏或星石数据代数不一致时拒绝带入并提示重新读取。

每位密探的携带命盘最多 3 项，一行一个词条；计数忽略空行与行首尾空白，同套不可重复。图鉴选满后须先移除再添加；手填超限或重复时就地提示，暂停自动保存并阻止草稿导出、配队图与操作图生成。旧版超限或重复的自由文本草稿仍可完整恢复或导入供修正，不截断、不覆盖原存档，修正后恢复自动保存。必须／禁用命盘是攻略要求，不套用实际携带的三项限制；仍保留自定义密探及手填词条能力，本次数量校验不等于图鉴合法性或全部游戏规则校验。

账号导入是独立快照，不写回密探、命盘或星石装备，不转移星石。生命与攻击复用现有自动／手动面板选择规则，自动面板遵守原权限与账号偏好，失败时保留已记录值并注明。配队图保留来源及扫描值待重算、突破待核对等提示；攻略内调整练度或配装后提示重新核对攻生，不自动重算。重新读取账号只更新候选快照，不覆盖已编辑阵容；切换账号先说明将打开另一份草稿，迟到请求不能进入新账号工作区。

「操作表」按回合成行、密探成列。点击单元格，在表下编辑当前密探的 `A / ↑ / ↓ / 圈`、目标与出手顺序；新增动作追加到全队末尾，同回合可多动。修改序号会移动动作并重排全队顺序，不覆盖其他密探的动作；非法序号保留原值。全队顺序展开区可改执行密探，保留上移、删除确认与撤回最后一步。每回合最多 50 个动作、最多 50 回合；五个敌方名称与备注仍可编辑。清空槽位保留动作并阻止缺人出图，删除回合确认后自动重编号。

编辑区遵循[效果图及实施对照](docs/design/battle-images/README.md)：五列配队表直接编辑练度，点表头选人，点命盘、星石或攻略要求在表下展开。命盘优先显示图鉴选项和真实说明，已选词条可移除；「自定义词条 / 编辑文本」保留自由文本与历史异常修正入口。必须／禁用要求仍独立保存。星石提供三主三辅六槽的名称、等级、品质和突破；继续写入 v1 草稿的 `stars` 文本，不新增账号装备写入。能明确识别的槽位可结构化编辑；旧说明、重复或未知格式完整保留在「原文本 / 其他说明」，歧义槽位须先整理原文。清空名称只移除该星石；输入非法或超过原字段 300 字限制时不覆盖旧值。配置修改不自动重算生命／攻击。

页头集中草稿管理与生成图片，取消常驻右侧预览。生成时按需展开图片预览和下载，可适应宽度、放大、操作分段翻页，首次打开定位到正在编辑的回合分段；「返回编辑」收起并回到生成按钮。打开预览后的草稿变化仍使旧 PNG 失效。手机保留五列和局部横滑，固定首列；表下编辑器使用屏幕宽度，选人候选可搜索，动作分行显示。选人或配置打开后聚焦标题，收起返回触发入口；未确认自定义名称在关闭／换槽前询问是否放弃。

两个视图分别生成配队图和操作图，导出固定浅色、1440px 宽 PNG。图片采用角色立绘表头、细线分隔和目标色块；未填写的必须/禁用命盘及星石行不占图幅，已填写信息完整保留。操作图先按五回合分段，超出像素上限时继续拆分；单回合或配队图仍过长时明确提示，不裁切内容。图片加载/编码失败可重试，已成功生成的分段仍可保存；修改内容或切换图片类型后会清除旧 PNG，实时预览自动更新，下载前需重新生成。手机可长按生成的图片保存，也可点击查看原图。

编辑后自动保存最近一份草稿到当前浏览器 localStorage，键为 `yh_battle_draft:v1:` 加 JSON 数组 `[站点用户 ID, 游戏账号 ID]`，游客单独使用 `["guest"]`。切换账号、退出登录或换站点用户分别恢复对应草稿，不自动复制游客内容；刷新后可继续编辑。存储失败明确提示并保留离开保护，损坏或无法读取的存档不会自动覆盖，须点击「覆盖本机存档」确认。新建及文件导入均需确认替换；清除浏览器数据会丢失本地存档，不提供跨设备云同步。

页头「草稿管理 → 导出草稿」下载可继续编辑的 JSON 文件，「导入草稿」先校验再替换，PNG 仍只用于分享。文件格式为 `{ "format": "yuanhub-battle-draft", "version": 1, "draft": { ... } }`，仅保留编辑字段，不包含来源账号 ID、令牌或私密养成备注；最多 1 MB、固定五槽位与五个目标、1–50 回合、每回合最多 50 动作，槽位及目标索引为 0–4，仅接受现有四类动作，文本长度与编辑器限制一致。导入不会写入养成档案，游戏须与当前账号一致，取消或校验失败保留原草稿；文件读取期间账号或草稿已变化时不覆盖。输出文本始终按纯文本渲染。

测试使用合成数据和 jsdom，不访问真实账号。真实出图效果由用户验收：在 390/768/1440px 手动带入两名密探，检查表内练度、命盘组合／要求、三主三辅星石以及表下编辑；在操作表给同一密探添加两次行动并调整全队顺序，检查两种 PNG、长按保存；编辑后刷新、切换账号再返回、导出后新建再导入，确认原练度与回合恢复且账号档案未改。原有 320/430/1024px、手机横屏、长备注分段、错误重试与深色主题固定浅色出图路径继续保留。

### 首页值守密探（V1）

标题与日期在页头左侧，右侧复用 `DataAccountContextBar` 内的 `AccountSwitcher`（游戏 + 当前账号名）；手机空间不足时仍在页头自然换行。桌面 Lobby 含页头约 316px，手机约 216px，长状态按内容增高。问候与真实资料状态在左，立绘向下自然裁切并锚定场景底部；暖白纸色减弱局部大肥鸟纹样，全站背景保留。通过「更换值守」按名字、拼音或首字母搜索并固定一位密探。状态复用已有登录、账号读取、资料读取、未知、尚未建档和全部就绪分支，部分建档不展示缺项提醒，不额外请求或推测活动数量。今日活动仅在账号辅助内容实际显示时使用双栏，否则占满内容区。

选择以 `yh_today_companion:user:<YuanHub 用户 ID>` / `yh_today_companion:guest` 保存到当前浏览器的 localStorage，用户与游客隔离，不随游戏子账号切换，也不跨设备同步。清除浏览器数据会恢复默认阿蝉；无法保存时页面会提示。立绘复用 `public/assets/operator-portraits/` 与现有目录，未提供立绘的密探暂不进入选择名单。问候按设备本地时间更新，活动日程继续按原服务器日期规则处理。

已有任一类数据后，Lobby 不再提示尚未建档的缺项，页面也不再展示可选补齐区。首次建档引导、读取失败与状态待确认提示继续保留。

V1 只支持固定值守，不包含每日随机、收藏轮换、跟随游戏账号、Live2D、Spine 或语音。

## 复刻要点

- **设计规范 v1.0**：骨架色（纸底 #F6EDD0 / 暖白卡 / 奶油 / 暖棕 / 茶棕）+ 点缀色（蜜黄 / 金橙 / 绛红 / 海盐蓝描边）全部保留为 CSS 变量。
- **交互**：Tab（作业/作业集/关卡）、站点筛选、搜索（标题/作者/密探）、排序（访问量/热度/最新）均为响应式 computed 过滤。
- **加载更多**：原站按钮无逻辑，复刻版实现了分页（每页 6 条）+ ‹ › 翻页。
- **详情页**：scrollspy 高亮 + 平滑锚点滚动 + 密探星级/星石/要点全数据化。
- **动效**：IntersectionObserver 滚动出现（v-reveal 指令，支持错峰 delay）、路由淡入淡出。
- **导航**：常用功能平铺直达，不增加分类标题；今日、密探、招募、库存、星石、账房依次显示，活动日历下移至账房之后。桌面侧栏底部“更多”弹出更新日志、内测、安装和教程；反馈中心保持直达，账号与连接码及登录后的通知常驻底部。≤1080px 顶栏持续显示当前页面和通知/登录，抽屉内“更多”展开同一批站点服务；账号与退出固定在抽屉底部。管理工作台仅按既有授权显示，已移除开发目标管理入口，其他管理详情继续高亮该入口。无效地址显示 404 页面和返回首页入口。
- **大饼中心已软下线**：反馈中心、反馈工作台、反馈广场与更新日志继续独立提供服务；保留开发目标页面源码、历史 API、权限与 `development_goals` 数据，不做迁移或删除。兼容和恢复范围见 [软下线说明](docs/ux/roadmap.md)。
- **实操教程**：从当前功能页的「使用教程 / 盘点教程 / 连接教程 / 登记教程」主动开始；新老用户都有稳定入口，提示跟随真实编辑区，不再显示全站任务按钮墙。Today 只在主动开始后选择本次所需的数据任务；MaaYuan、招募、安装和星石保留各自真实验证机制。关闭不清草稿、不撤销业务，回到功能页按真实状态恢复；已有成果提供复习路径，无需重复建档。入口与完成条件见 [页面内教程策略](docs/plans/global-navigation-onboarding-policy.md#页面内实操教程2026-10-08-最终收口)。
- 原站 10 条作业数据中，仅「阳泰山府10 无庞统」有详情链接，其余卡片不可点击（与原站一致）。
- **广陵账房页**（`/cart`）：由 `yuanpaid`（React 版游戏礼包购物车）迁移，数据（101+41 个礼包、28 档累充奖励）逐字保留，交互逻辑（限购、汇率、筛选、自定义、导出图片）忠实移植，并按设计规范 v1.0 整体重新上色。
