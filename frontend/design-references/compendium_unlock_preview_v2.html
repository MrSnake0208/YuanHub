图鉴解锁动画方向 · v2

这版按你的要求做了三类调整：Scanner 只保留纵向扫描、Pixel 改成黑暗风、 Rune 去掉扫描线，仅保留符文 / 法阵 / 涟漪。

1) 稀有度 Scanner（最小化扫描版）

这一组都共用同一套动画逻辑：扫描线从上到下确认条目 → 图像显现 → 卡片稳定落到已解锁态。 适合做统一的“稀有度通用特效”。

🦁
RARITY V

Gold · 5 星通用特效

去掉了原先后续那段转了小半圈的高光，只保留干净的纵向扫描。现在更像“高稀有度条目被正式记录”。

🦋
RARITY IV

Purple · 稀有度 #9483bf

同样是最小化扫描，只把完成态与扫描高光切到紫色稀有度。适合“稀有、秘术、梦境、异界”之类的分类。

🐬
RARITY III

Blue · 稀有度 #9bb5cf

蓝色版本显得更冷静、系统化，适合较高级但不神秘的条目，或者偏科技 / 编录 / 观测的图鉴体系。

2) 黑暗风 Pixel Scanner

这一版整体压暗了，像是废弃终端 / 阴冷数据库 / 夜间扫描屏。动画不是“可爱像素”，而是更偏故障、压抑、暗色 CRT 的方向。 你说“有一个很适合的人选”，如果你把那个参考发我，我可以继续把这版往那个具体对象 / 风格靠。

☠️
NO SIGNAL

Dark Pixel · 黑暗扫描

扫描线更粗、更冷，配合轻微 steps 抖动和噪点显现。适合危险条目、被污染条目、夜间终端或敌对阵营图鉴。

这一块建议下一步：
你把“很适合的人选”发来后，我可以继续基于这个黑暗像素骨架做定制版，比如：
  • 更偏恶魔图鉴 / 禁忌档案
  • 更偏地牢 / 旧掌机 / Rogue-like
  • 更偏黑客终端 / 生体识别
  • 直接做成角色专属识别特效

Reserved Slot · 预留位

先留出一个槽位，后面可以按你的人选继续做变体，不必推翻现有结构。

3) Rune（无扫描线）

这一版不再有“系统扫描”的意味，而是纯粹的“法阵激活 → 符文旋转 → 涟漪扩散 → 条目显形”。 如果你也有人选参考，后面可以继续把符文密度、线条复杂度、神圣感 / 邪异感继续细化。

🦉
SEALED

Rune Only · 符文 / 法阵 / 涟漪

没有扫描线，重点完全放在法阵与符文显现。比 Scanner 更有仪式感，也更适合剧情型、神秘型或召唤型条目。

后续可继续分叉的方向：
  • 圣洁 / 银白 / 月相系法阵
  • 邪术 / 黑紫 / 封印裂开系法阵
  • 炼金 / 几何阵 / 文献感更强
  • 角色专属的徽记 / 宗派纹样

Reserved Slot · 预留位

如果你把“可用的人选”发来，我下一轮可以直接往具体视觉母题上走，而不只是在抽象符文层面试探。

我对这版的建议是：
1. 5 星通用特效 就用这版 Gold Scanner，已经足够干净；
2. 紫 / 蓝 可以直接共用同套组件，只换 CSS 变量；
3. Pixel 与 Rune 现在更像“方向样机”，等你把参考人选给我后，最值得继续往下打磨。
