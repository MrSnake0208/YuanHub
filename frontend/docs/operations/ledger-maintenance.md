# 广陵账房维护

通过 `/manage` → 内容维护 → 广陵账房管理（`/admin/ledger`）进入。账号必须具备 `ledger_catalog:write`，由平台管理员/超级管理员默认拥有；后端也会独立校验。

## 三个工作区

1. **礼包目录**：搜索名称/ID，展开筛选条件选择游戏、状态、分类；新增时确认 USD（代号鸢）/CNY（如鸢），填价格、积分、小数抽数、限购、分类、排序与补充说明。核对公开预览再保存。停用用编辑页取消“启用”，保留 ID 和历史资料，不硬删除。
2. **累充活动**：新增草稿，选择适用游戏，填完整带偏移的开始/结束时间和 IANA 时区（通常 Asia/Shanghai）；添加任意多个档位、奖励和顺序。取消档位启用即停用档位。核对预览后改“发布”并保存确认；草稿、停用不在公共账房展示。已发布活动编辑保存也需确认。未开始和已结束均不表示当前可领取。
3. **默认设置**：更改公共 USD→CNY 默认参考汇率，只影响没有自选汇率的新预算。用户手改及已保存方案的历史汇率优先，如鸢直接人民币计价。

保存后用户刷新 `/cart` 即读取已发布数据，无需为每个新礼包发前端。首次功能上线仍需正常部署前后端。本任务没有部署。

未保存离开会确认；保存失败保留编辑内容，错误摘要获得焦点，可通过链接定位字段。遇到“其他管理员修改”时请先保留需要的文字，再返回列表刷新，以最新版本重新修改，不能强制覆盖。

## 历史与故障

原142个礼包和原始数值保留。两期旧累充的结束时间仍为2026-04-29、2026-05-13，均为历史。旧来源没有开始日期和明确游戏范围，按旧页面两游戏展示保留4份游戏限定历史记录，并显示待核实说明；请核实后停用不适用记录或创建新活动，不要直接延长旧日期。历史记录编辑如果要改结束时间，必须补齐真实开始时间。

私人方案始终以保存时的礼包快照计算，改价、改名、下架不会追溯改动旧方案。页面加载期间已选商品也保留选购时快照。用户个人礼包不会上传为公共商品；两游戏的购物车和方案独立。游客 `yh_ledger_plans` 及登录方案保持原逻辑。

目录读取失败会明确提示使用带时间的上次成功缓存，或标明“内置迁移数据，不是最新发布数据”。可点击“重试读取目录”；不要将这些过渡数据当作最新商品。读取失败不会清空购物车。服务端明确返回空目录时显示暂无可售礼包，已选快照仍保留。

公开 API 是 `/hub/ledger/catalog`，管理 API 是 `/v1/admin/ledger`。所有公开字段和管理员表单使用同一契约；HTTP不缓存，每次刷新重新请求。前端仅保留成功验证的公开缓存 `yh_ledger_catalog_v1`，没有实时推送或实时汇率。
