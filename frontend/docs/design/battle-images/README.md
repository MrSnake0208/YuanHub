## Implementation Plan

1. 保留当前路由、站点导航和账号选择器；页头集中标题、保存状态、草稿管理和生成图片。取消常驻左右编辑／预览双栏，预览按需展开。
2. 用五列可编辑配队表替换单人长表单。点头像选人；点命盘、星石和攻略要求展开当前槽位配置。空槽位可搜索图鉴或填自定义名，账号快照优先带入。更换仍确认覆盖范围。
3. 命盘默认图鉴选择（真实名称和说明），保留文本编辑、自定义与旧版超限词条。星石按三主三辅编辑，继续序列化到原 `stars` 文本；无法识别的原文完整保留并提供原文本入口，不自动迁移／截断。
4. 操作表直接选择回合与槽位，下方编辑动作／目标／全队顺序，新增动作默认追加；保留切换密探、撤回、删除确认和回合备注。序号重排移动动作而非覆盖其他动作。
5. 更新组件测试、相关数据自检与 README，检查效果图中的结构逐项存在。浏览器未获本任务授权，不执行页面截图或真实视觉验证；提供手动验收路径。

## 保护边界与状态

草稿管理菜单使用全站 `--z-popover` 层级；双端 CSS 保留全局 `.battle-*` / `.page-battle-images` 命名空间，为页面、共享子组件和 Teleport 弹窗提供样式，并由样式归属测试检查各端媒体边界。

玩家最短路径：选择密探 → 表内填写／表下配置 → 切操作表记录 → 生成图片。已填写内容切视图不丢失；账号、访客、本地草稿隔离与迟到请求保护继续使用现有逻辑。加载／读取失败保留状态和重试。零数据保留五个空槽，未知仍为 `—`，不默认当零。

携带命盘最多三项，同套不重复；历史超限完整展示，修正前阻止保存／导出。星石编辑不写回账号档案，不自动计算生命／攻击。草稿仍为 v1 JSON，无后端／API 变更。

320–767px 表格内部横滑，首列固定，提供可聚焦区域与滑动提示；详情回到全宽。768px 以上按可用空间自然展开；不改变浏览器缩放。选人和表下编辑使用同页区域，主动打开时移到标题焦点，收起后回到触发按钮。错误保留文字、字段关联及定位入口。
