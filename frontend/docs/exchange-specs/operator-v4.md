# 密探交换 v4 接入

当前完整备份推荐[v5（含等级突破与观测快照）](./operator-v5.md)。
只交换密探，复用v3传输/账号映射/分区语义。v4可保存独立化极，完整突破备份应使用v5。完整规则见[独立化极与v4协议](../operator-growth-data-exchange-protocol-v4.md)，机器Schema见[正式v4](../schemas/operator-growth-exchange-v4.schema.json)。

新客户端读取catalog能力和current.huaji；不得以level/elite猜拥有，缺失awake不得确认false，stage未知不算材料/战斗。PATCH局部huaji与交换完整huaji的字段出现性不同。旧v2/v3及Maa反复30永久兼容；无法无损表达独立觉醒时用v4，不改旧字段含义。SP422保护仍生效。
