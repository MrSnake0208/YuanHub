# 羁绊图鉴

作者：线线&悠扬 · 独立创作。

玩家入口 `/bonds`，目录管理 `/bonds/admin`。复用本站账号切换、密探目录/头像/拥有状态及站点样式，不持久化第二套个人名单。玩家页面沿用现有构建期功能开关 `BOND_ARCHIVE`，开发与生产构建均开启。入口、路由、页面及全部玩家接口（含目录读取、收录与备份导入导出）沿用本站登录和内测准入，有内测资格的普通用户无需 `archive:access` 或管理员角色即可使用；无资格、维护或资格查询失败时不放行，管理员沿用现有内测豁免。账号归属与个人数据隔离保持。目录管理仍需 `archive:access`、`bond_catalog:write` 和配置的资料所有者身份，不随玩家功能开放。部署时先更新后端，再更新前端；本次未部署。

## 使用

1. 图鉴统一为一套天气、行动快捷筛选，默认「按密探」展示；筛选底行的「按密探／按配对」只切换展示并保留条件，不预设天气。天气、行动标签与选项桌面同行，手机将天气和行动各排四列两行，组标题旁的「全部」只清除本组条件；两端共享同一筛选条件；收录状态直接选择「全部／未收录／已收录」，「未收录」统一承担隐藏已收录的用途，不再设置重复开关。「仅显示成员均已拥有的组合」要求所有成员均拥有，未读取拥有资料时不可选。效果与资料范围位于「更多筛选」。两个视图共用结果摘要、收录状态图例、清空筛选及批量收录入口；清空恢复当前图鉴和全部天气/行动，不修改账号记录。可按密探名称、别名、拼音或缩写搜索，同时输入两个名称（空格或顿号分隔）查找指定配对。每页20组，筛选和切换视图回到第一页。
2. 按密探独立展开/折叠，再按配对与羁绊效果显示实际天气。同一配对行动一致时放到标题旁，否则按行动分组。按配对视图按成员与行动分组，结果使用单列行分隔布局，避免双列大卡片；所有天气效果一致时只在组标题显示一次，否则逐天气显示真实效果。两种视图都以整格天气按钮收录，桌面用图标、名称和加号/勾选替代重复「标记收录」按钮，未读取、不可收录和历史状态仍显示文字。桌面天气根据容器宽度排成2／4／8列（520px起4列、1040px起8列），页面沿用原有1180px最大宽度，配对标题位于天气上方；手机380px以下2列、380px起4列；380–559px批量模式恢复2列以容纳勾选文字。三人及长名称完整换行，不补不存在的条件。同一条目可出现在多个密探下，收录共用 `bond_id`。密探进度按完整当前目录去重，不受筛选影响；顶部统计沿用服务端 summary，「我的密探」取当前游戏真实拥有资料，未读取时显示「—」。
3. 登录并选择账号后，点击天气格切换布尔收录状态，再次点击取消，不弹详情、不累计次数；保存时原格显示加载图标，成功后同步所有副本、分组和顶部进度，失败保留原状态。批量选择从列表工具栏的「批量收录」进入，最多50条，可选择收录或取消选中项，退出即清空选择；无需打开设置。未读取及不可收录的历史条目不可新增收录。设置保留刷新和备份迁移。未填写拥有资料时显示全部，不创建第二套名单。
4. 「设置 → 备份迁移」可导出当前账号完整 `yuanhub-bonds` schema_version=1 文件，包含历史记录。导入原生文件或旧助手JSON均须预览并确认；不会自动创建/同名关联账号。旧文件明确选择来源和目标，缺失游戏信息时必须选择；默认仅合并已记录项，false/缺项不清空。
5. 自动进度来自同账号羁绊；人工完成状态独立，需要用户确认。取消不撤销已确认成就、不发放库存奖励。

管理员仍用管理工作台「羁绊目录」维护：新增组合/天气或读取已授权转换文件，核对待处理数量，合入本地草稿，保存、预览发布并明确确认。修改成员/行动/天气必须新增身份；效果/状态可保留ID更正。未确认游戏可用性的资料不得发布。

累计包括当前和历史下架的已记录种数，误录不计数；当前图鉴比例另以active计。本站更新时间不代表游戏内首次触发。读取失败显示错误而非0%；保存只在服务器成功后更新状态，失败无“已保存”假象。409刷新当前档案并提示重试；管理编辑冲突保留本地草稿，可先导出再重新读取。

切换账号/退出立即清除旧档案，迟到请求不得回灌；保存/文件操作期间禁用切换。文件、来源、目标、游戏、策略、档案revision或目录版本变化均使预览失效。未知记录需明确跳过，非法/不匹配记录阻止整批。__missing__及外部游戏可用性覆盖不迁移到拥有资料。服务重启后预览需重做。

## 数据维护边界

真实目录、待核实资料和导入结果仅保存在仓库外私有位置。生产目录由所有者手动导入数据库并发布；页面数量以当前已发布目录为准。资料使用须核实授权范围，本地导入授权不推定代码、素材及对外分发授权。

## 最小人工验收（未执行浏览器）

1. 使用无管理权限的普通内测账号，从桌面/手机导航打开 `/bonds`，默认按密探展示，可切游戏、搜索、展开密探并收录；无内测资格时隐藏入口，直达路由进入内测页，玩家接口也拒绝访问。撤销资格或资格读取失败时不得继续操作，目录管理仍不可进入，收录仍校验账号归属。统一筛选直接选择天气和行动，检查同一配对只出现一次，清除天气后可见该配对的完整天气条件。390px及1440px检查分组、筛选、天气卡和键盘焦点，补查320/430/768/1024px及手机横屏，无整页横向溢出。
2. 登录选账号A，点击两个不同天气卡，顶部当前进度增加2；同条目在两名密探下同步，只累计一次，再点取消减1。筛选/隐藏不改变分组与顶部进度，切B后无A记录，返回A仍正确。从列表工具栏进入批量收录，勾选同条目的两个副本，应只选择/保存一次。
3. 两个窗口编辑同一账号，后保存窗口出现版本冲突并刷新；模拟断网保存显示失败，不显示新“已记录”。读取失败与空目录/无结果应有不同提示。
4. 从「设置 → 备份迁移」导出A备份，到同游戏测试账号B预览恢复并重复导入，数量不累加。旧文件选择来源/目标，缺游戏必须选择，unknown需确认跳过；更换目标后旧预览不能确认。
5. 成就页筛选羁缘，进度只读；达标后手动确认，再取消羁绊，完成状态保留。管理员查看目录、改效果、保存草稿/预览；发布会修改公共目录，应仅在另有授权的测试环境手动操作。

非浏览器检查分别位于 `test/bonds.test.js`、`behavior/bonds.spec.js`、`behavior/bondsAdmin.spec.js` 及成就行为测试。实际结果见工作区任务验证记录；组件测试不能替代真实布局、触控和浏览器下载验收。

## 私有资料维护

羁绊目录只从数据库读取；所有者手动导入并发布，启动与部署不补资料。管理入口受部署端本人账号限制。羁缘目标来自目录响应 achievement_targets；未配置时显示资料尚未配置，不显示全部达标或固定门槛。真实组合、pending 与备份不得进入仓库或构建包。

## 手机展示

手机（≤767px）保留导航栏标题，正文标题仅供辅助技术读取，作者、账号和设置紧凑排列。仅本页手机页头收紧上下留白和署名间距；进度摘要收紧间距，羁缘与拥有统计采用标签/数值并排，保留计算口径和成就确认说明。天气与行动均保留直接点选，手机每组8个选项排为四列两行，组标题旁提供「全部」按钮，只清除对应天气或行动；桌面继续保留原快捷按钮排布。两端共享筛选状态，选择立即更新结果，不增加完成、下一轮或沉浸模式。搜索占位简化为「搜索密探或配对」，多名称分隔规则在聚焦时显示并通过 aria-describedby 关联。手机拥有筛选显示「仅看全员已拥有」，辅助技术仍读取完整的全员拥有语义；拥有统计说明简化为「按当前账号统计」。更多筛选、收录状态和两种查看方式继续可用。结果摘要与批量入口同行，手机不重复显示已由筛选按钮选中态表达的天气/行动；加号/勾选说明只在列表工具区保留一次，不在每个密探内重复。工具区以不透明主题底色遮住下方鸟纹，并用正文色显示结果与说明，不增加边框卡片；桌面布局和1180px上限保持。

天气格保留图标、完整名称和加号/勾选：320–379px为2列，380–767px为4列；380–559px采用更紧凑图标，保持13px名称与44px最小格高，8种天气排两行。380–559px批量模式恢复2列，560px起仍为4列，保留完整选择文字。保存时在原格显示加载，失败保持旧状态，未读取、不可收录和历史状态继续显示文字。深色状态沿用主题变量，不改变桌面1180px宽度、存档或权限。

人工验收：320/379/380/390/430/559/560/767/768px检查天气/行动直接点选、各组「全部」按钮、天气列数、批量模式与桌面切换；账号长名称、搜索、进度计数不越界；点天气收录再取消，确认加号/勾选与进度同步，保存失败保留原状态。浏览器与真机触控未由本次代码检查验证。

常规收录不显示页顶保存中/成功横条，也不预留空白；通过条目的加载图标、勾选及进度更新反馈结果，失败和冲突仍明确报错，导入结果提示保留。列表工具区收录说明不随 busy 切换而卸载，避免保存前后的高度变化干扰滚动导航。羁绊页面手机导航使用不透明主题底色，滚动自动显隐逻辑保持不变；长错误提示仍可自然展开，不裁切。真机需复查连续收录/取消时导航是否保持稳定、正常手动滚动是否仍可显隐。
