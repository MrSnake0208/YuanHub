# 更新日志

正文按 JSON 文档复制，支持 Vue 响应式根节点和嵌套图片，显示图片时不改写原始数据。正文异常显示局部错误及重试入口，版本标题和日期仍保留；后台预览也使用同一个阅读组件。

每个版本展示最多三条真实段落或列表摘要，不生成未经作者写明的内容。摘要规范化空白，精确排除与日志标题相同的段落及重复段落，再取三条；相似但不同的文字仍保留，原始正文不改写。最新公开日志默认展开完整正文，其他版本可按需阅读。保留正文图片、原生外链及关联反馈。

版本卡片使用 `version-<版本记录编号>` 作为页面锚点。首次载入深链时通过公开分页接口查找目标并展开、定位；每次最多自动查找五页，仍未找到时可继续加载更多，全部读完仍无目标则提示未找到公开日志。后续页加载失败保留前页，重试继续失败页。普通访问只加载首批；组件卸载后不继续翻页或滚动。

页头「站点版本」来自当前前端构建，首条记录标注「最新公开日志」；两者不要求相同，不据差异判断部署错误，也不改历史日志的版本标签。

后台日志编辑在切换条目、新建、翻页、冲突重新加载和路由离开前统一确认放弃草稿；刷新/关闭使用浏览器原生提示。拒绝确认或重载失败保留标题、版本标签与正文；保存失败与409不会清掉草稿。保存和图片处理期间暂停编辑、条目切换及重复操作，成功保存后不再提示离页；用户身份改变或卸载后，旧保存/上传/确认响应不覆盖当前编辑器。草稿不自动写入浏览器持久化存储。
