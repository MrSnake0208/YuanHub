丰收 / 稻穗元素 · 图鉴解锁动画

这次不再强调“扫描”，而是把丰收主题拆成四种不同的动画语义：生长、加冕、风吹稻田、种子涟漪。

🌾
DORMANT

A · 稻穗生长

从卡片底部长出几根稻穗，同时中央亮起一瞬暖光。最直观地表达“成熟 / 收获 / 生长完成”。

🏆
UNCLAIMED

B · 麦穗冠 / Harvest Wreath

两侧麦穗聚拢成类似桂冠的结构，更像“丰收荣誉 / 达成 / 稀有收藏”。如果是高星级或成就类条目会非常合适。

🌕
UNKNOWN

C · 风吹稻田 / Harvest Sweep

底部先浮出稻田纹理，再有一道暖色光像风一样掠过。这一版最适合做“通用丰收主题解锁”，不会太具象。

🌱
SEALED

D · 种子涟漪 / Seed Ripple

中心像种子落入土地一样扩散几圈暖色涟漪，再甩出少量谷粒。比符文法阵更自然，也更有“丰饶祝福”的感觉。

我个人最看好 C 和 D。 C 更适合作为“丰收系通用主题”，因为不会把画面塞满稻穗；D 更适合特定角色或有祝福 / 农耕 / 土地意象的条目。 如果你想把它和之前的 5 星金色 Scanner 结合，最自然的是：先纵向金色扫描，再在结束点补一个很弱的 D 式涟漪，而不要把两套完整动画叠在一起。
