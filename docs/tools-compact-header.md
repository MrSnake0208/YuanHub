# 工具页紧凑工作栏

库存、密探名册、星石背包和礼包预算共用 `src/components/CompactToolHeader.vue`。宣传页、内测介绍和反馈页沿用各自布局。

页头只负责 `title`、可选一句 `description`、`account` / `actions` / `help` 插槽。标题为 22–24px，上下内边距各 12px；按内容宽度重排，不固定高度。账号条的 `compact` 参数只影响展示，账号切换仍使用原有个人中心入口。统计与筛选留在页面。

- 库存：页头「录入库存」进入当前道具／心纸清单的原有编辑流程；从统计或历史进入时先返回清单。概览的「最近完整盘点」使用当前库存的完整基准时间，目录日期单独标注。两者按正文大小显示，窄屏整项换行。
- 密探：页头提供录入；图鉴保留搜索和招募状态，属性、职业、品质、养成条件进入「更多筛选」。养成总览常驻名称搜索和状态筛选，复用已有搜索匹配函数，其余条件可展开。关闭筛选面板不清除条件。
- 星石：无页签偏好时默认进入「背包与核对」，已有页签偏好和采集恢复逻辑保持原样。「导入截图」进入既有识别流程；资源加载说明仅在该流程显示，页头入口附近及上传区仍保留本机图片处理提示。
- 账房：版本和结算币种放在页头，「我的方案」常驻，保存入口收入「更多」；搜索、分类、排序直接接商品。汇率值可见，展开设置后显示输入与参考汇率说明；窄屏仍使用原有底部总价和清单抽屉。

帮助默认收起，可随时展开。更多操作选中后收起，并先把焦点还给触发入口，供后续弹窗正确恢复焦点。

## 验证范围

本次为 L2 展示／响应式交互改动。未改计算、模型、权限、路由或后端接口。

Agent 的定向编译与 Playwright 检查使用隔离的合成数据预览，不代表真实账号端到端通过。视口为 320、390、430、768、1024、1180、1440px，高度 800px；覆盖各页首屏、帮助、更多、录入入口、筛选、星石导入提示、账房移动清单、空态和长账号名。

用户／CI 最小回归命令（在 `YuanHub` 目录执行）：

```sh
npm run test:behavior -- behavior/{compactToolHeader,inventoryStockBaseline,inventoryRecordsUx,operatorFilterDossier,operatorDiscardedGroup,starRecoveryUx,cartPlanIntegrity,cartSafetyUx}.spec.js
```

真实账号另检查上述五个需求视口的首屏，以及录入、导入、方案弹窗的原有流程。无需为此布局改动默认跑完整 CI。
