# 工具页紧凑工作栏

库存、密探名册、星石背包和礼包预算共用 `src/components/CompactToolHeader.vue`。宣传页、内测介绍和反馈页沿用各自布局。

页头只负责 `title`、可选一句 `description`、`account` / `primary` / `actions` / `help` 插槽。宋体茶棕标题在手机为 24–26px，宽容器为 28px。唯一主操作进入 `primary`，帮助与更多在独立辅助区；统计、Tabs、搜索、筛选和业务状态继续由页面组织。

内容宽度不足 760px 时，第一行是标题和主操作，第二行是上下文与帮助／更多；宽容器重排为标题、上下文、主操作、辅助操作。帮助、更多与账号入口保留 44px 点击区域，辅助操作使用轻文字／小图标视觉，避免按钮墙。

`DataAccountContextBar compact` 单独渲染奶油细描边链接 selector「代号鸢 · 账号名 ⌄」，长名称截断，title 与可访问名称保留完整身份。点击沿用个人中心账号管理；未登录沿用登录回跳，加载、空账号和错误仍可读。完整模式保留原管理按钮与说明。

三个工作区 Tabs 复用 `src/styles/tools-workspace.css`，取消整行大圆角外框，以局部下划线表示当前项；手机也在正文顶部显示 Tabs。

- 库存：唯一主操作「录入库存」进入当前道具／心纸清单的原有编辑流程；从统计或历史进入时先返回清单。最近完整盘点与目录日期压成辅助 metadata，类型、搜索、持有状态取消外层大卡片。
- 密探：唯一主操作「录入密探」。概览压成 metadata，仅显示目录更新日期；完整目录版本在 title，并在更多筛选内保留原只读复制字段。搜索框、招募状态、更多筛选直接衔接已有卡片；宽屏一行，手机搜索独占一行、状态与更多下一行。去掉重复概览，保留筛选结果、同步错误和原卡片。展开筛选仍使用原条件，关闭不清除；「更多筛选 · N」只统计属性、职业、品质及已启用的养成范围，不统计常驻搜索与招募状态。
- 星石：已有页签偏好和采集恢复逻辑保持原样。「导入截图」进入既有识别流程；「截图识别」仅在进入导入后显示为只读阶段；「背包与核对」用于回到工作区，导入动作不再常驻 Tabs。普通云端成功状态缩成概览内「✓ 已同步」，读取／保存仍如实显示；错误、警告、重试保留明显边框。资源加载说明贴近识别工作区，本机图片处理提示保留。
- 账房：版本用原生 selector 呈现并复用原切换方法，选项保留已选礼包数量；结算币种是辅助文字；唯一主操作「我的方案」，保存收入「更多」。搜索、分类、排序留在正文。汇率值可见，说明仍贴近设置；窄屏原底部总价和清单抽屉保留。

帮助默认收起，可随时展开。更多操作选中后收起，并先把焦点还给触发入口，供后续弹窗正确恢复焦点。

## 验证范围

第二轮为 L2 展示／响应式改动。未改计算、模型、权限、路由或后端接口。

Agent 的定向 SFC 编译与 Playwright CLI 检查复用现有开发服务，在独立浏览器会话中使用合成资格／账号响应，不代表真实账号端到端通过。视口为 320、390、430、768、1024、1440px，高度 800px；检查首屏布局、帮助、更多、原主操作、账号管理入口、筛选与长账号名。


真实账号另检查 390 / 768 / 1024 / 1440px 首屏，以及账号管理、录入、导入、方案弹窗的原有流程。无需为此布局改动默认跑完整 CI 或无关后端测试。

- 密探：招募状态改为浅蜜黄选中态，移除头像 Grid 外层大框；保留头像、状态、养成和卡片交互。390px 保留三列；768px 页头稳定两行，搜索与高频筛选合为一行。手机目录日期退入可复制的更多筛选，metadata 保留图鉴、招募与比例。
