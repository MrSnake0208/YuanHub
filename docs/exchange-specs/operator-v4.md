# 密探交换 v4 接入

只交换密探，复用v3传输/账号映射/分区语义。当前推荐无损备份版本为`myshare-operator-exchange@4`。完整规则见[独立化极与v4协议](../operator-growth-data-exchange-protocol-v4.md)，机器Schema见[正式v4](../schemas/operator-growth-exchange-v4.schema.json)。

新客户端读取catalog能力和current.huaji；不得以level/elite猜拥有，缺失awake不得确认false，stage未知不算材料/战斗。PATCH局部huaji与交换完整huaji的字段出现性不同。旧v2/v3及Maa反复30永久兼容；无法无损表达独立觉醒时用v4，不改旧字段含义。SP422保护仍生效。
