# 信赖与传闻

入口：密探名册 → 信赖与传闻。首版由用户录入游戏内的当前信赖值和已解锁传闻数量，仅展示已拥有密探；未记录与明确填写 `0` 分开处理。当前正式奖励规则尚未核准，页面显示“资料待补”，不会给出完整奖励总额。

## 使用与计算

选择密探后点击“编辑进度”；保存仅提交发生变化的字段。留空保存表示清除该项记录。传闻变化不自动增加信赖值。保存失败保留草稿；版本冲突需重新读取、核对后保存。

完整规则可用时，按当前值显示下一奖励档位和差距；未解锁收益只包含阈值高于当前进度的档位。已达标但尚未领取的奖励不在统计内。未记录或规则不完整的领域不计入收益，页面同时展示覆盖数量。显式共享的信赖只汇总一次，传闻各自计算；搜索与筛选不影响全账号汇总。

## 独立备份

“更多 · 信赖与传闻备份”可导出当前账号全部已记录数据，包含列表之外的历史记录。格式 `yuanhub-relationships`，版本 1，与练度 JSON v5 分开；不包含预测奖励。恢复必须同游戏、密探 ID 有效，最多 1 MiB / 1000 位。

恢复先预览目标账号、修改数量、冲突数量及旧值到新值。默认保留当前已记录值；勾选覆盖才采用备份冲突值。恢复使用绝对值，不累加，不删除备份之外的字段。共享信赖冲突或超上限时整批拒绝，确认恢复仍接受服务器版本校验。

## 人工验收（尚未执行）

1. 在桌面和手机打开新页签：检查长名称、窄屏折行、键盘页签与焦点；建议宽度 320/390/430/768/1024/1440px。
2. 编辑一位密探，保存 `0`，刷新确认仍为 `0`；再留空保存，应显示“未记录”。
3. 输入未保存内容后切页签、切账号、离开页面：确认保留/放弃提示；保存中不得误写到另一账号。
4. 导出备份，修改一项值后预览恢复：默认保留当前值，勾选覆盖后展示旧值→新值，确认后再读取核对。
5. 检查奖励资料待核准提示；不得把缺失规则或未录入值显示成“剩余奖励为零”。
