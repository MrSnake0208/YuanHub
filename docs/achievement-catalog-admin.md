# 成就目录管理操作

入口：「管理工作台 → 内容维护 → 成就目录管理」，路径 `/achievement/admin`。平台管理员和超级管理员默认获得 `achievement_catalog:write`；即使普通玩家成就入口未开放，也可以整理资料。新实现首次使用需要正常发布前后端代码，之后日常新增/修改/发布不再改代码或 JSON、不再重新部署。

1. 选择代号鸢或如鸢；新增分类，再新增成就。游戏、成就 ID 和分类 ID 由系统维护，名称不会影响个人记录关联。
2. 填写成就名称并选择分类；条件、奖励均选填。不需要核验日期或逐条标记已核验。没有明确目标就留空target，不填0/1；填写目标时只用正整数。奖励选择“资料未补齐 / 确认无奖励 / 已知奖励”，已知奖励逐行选择物品与正整数数量。草稿保存后玩家暂不可见。
3. 保存后点预览发布，核对新增/修改/退役，再确认发布。目录自动区分空目录和部分收录，无需填写范围说明；只有主动确认整库齐全时才在选填设置中选择完整收录。玩家刷新后即可记录自己的完成状态、进度、关注和备注。
4. 批量维护打开“批量导入、导出与发布历史”。导出带稳定 ID 的草稿后编辑 JSON；省略 achievement_id 表示新建，未知指定 ID 不按名称合并。先预览新增/冲突/非法/未匹配，再确认合入草稿；默认保留冲突，明确选择更新才覆盖。导入后可直接预览发布，文件缺失项不自动删除。
5. 历史版本可对比并回滚，回滚发布为新版本。存在未发布草稿先导出、明确放弃再恢复。最近5个旧版本可用；降低或清空已发布数值目标会被阻止，回滚同样如此。

退役只从玩家当前目录移出，保留状态、关注、进度、备注、日期和备份。分类下有有效成就时禁止停用，先迁移或退役；顺序决定公共分类顺序。目录写冲突会保留本地输入；可复制需保留内容后重新读取核对，不自动覆盖另一位管理员。

已保存草稿不会因离开页面丢失；未保存编辑离开、刷新或切游戏会提示。已发布导出来自服务器；草稿有未保存修改时可导出本地草稿保留，再重新读取核对冲突。导入预览15分钟过期，后端重启或请求落到不同实例需重做。

导入只合并成就和分类，范围自动按目录内容确定；不会把几十条成就自动宣称为整库完整收录。已有待核验、核验日期为空或奖励为空的草稿不需要重新导入，可以直接预览发布。发布错误按成就名称合并，点击名称可进入编辑。取消发布预览不会删除已保存草稿。新目录条目只接收已确认10字段，不再接收旧核验或扩展字段。

协议及数据库说明见后端 `docs/achievement-catalog-admin.md`。资料来源、别名、完成方法和章节的表单与玩家展示已移除，管理页仅搜索名称或 ID；旧目录非空字段会显示逐项兼容问题并将目录设为只读，提供原始文档导出；需要另行核对迁移，不能以新结构覆盖旧资料。

## 人工验收（本轮未运行真实浏览器）

使用当前开发服务；如果尚未加载新代码，需要用户按仓库 `./dev.sh` 流程安排更新，不重复启动服务。测试 fixture 不进入正式目录。

1. 有权限账号从工作台进入；普通账号无入口且不能调用管理 API。需要同时具有 `archive:access` 和 `achievement_catalog:write`；仅平台管理员角色不可进入。先检查390px手机和1440px桌面，再补320/430/768/1024px及手机横屏。
2. 新增分类/成就或导入简要JSON并保存草稿；另开玩家页面刷新，发布前不可见。名称为空、无效分类或非法进度规则会阻止发布。
3. 编辑器没有资料来源或核验表单，不填写奖励仍可预览确认发布；玩家刷新看到成就并可记录完成状态，列表不显示来源链接；切另一游戏确认未变化。
4. 对已有记录的成就更名发布，确认状态、关注、进度、备注、完成日期不变；退役后完整导出仍包含历史记录。两个管理窗口用旧修订保存/发布须409，不覆盖新修订。
5. 导入JSON分别核对默认保留冲突/明确更新/非法整批拒绝/未知跳过；范围自动生成。历史对比、取消、回滚新版本及有草稿阻止回滚；手机编辑返回列表、键盘/触控/保存可达，长ID不撑破页面。

## 本阶段交付与人工验收补充

公共条目为 achievement_id/game/category_id/name/condition/sort/is_hidden/rewards/target/linked_metric。管理列表每页50条，分类顺序优先于组内排序；手机先返回列表再翻页，奖励输入保留。字典来自服务端 reward_items；不手填物品键。奖励行错误明确提示并关联控件，保存失败聚焦错误摘要并保留所有输入。可在错误摘要跳到对应成就/奖励行。

首次Excel离线JSON使用import_category_0等临时分类引用，省略成就ID；由后端生成正式分类/成就ID。后续必须保留系统ID，不按名称合并。全量转换产物位于工作区achievement/converted，本阶段仅离线生成，不操作实际数据库或发布。

在用户后续安排的可抛弃测试环境，手机390px与桌面1440px各检查：选择物品和数量→填写0触发行错误→改为正整数→翻页/筛选后输入仍在；target留空无数值进度、填写整数才出现；羁绊配置显示尚未接入。再用320/768px检查换行与长中文条件，无页面横滚。目录/个人备份分别导出再预览，核对目标游戏和账号；不确认真实数据导入或发布。既有旧目录看到兼容只读提示时，先导出原始文档，不强行保存。
