# 管理工具快捷导航

在「管理工作台」的工具卡片下点击「固定到导航」，即可在桌面侧栏或手机导航抽屉的「常用管理」区域直接进入该工具。点击「取消固定」移除快捷入口，工作台中的工具保持可用。

- 默认不固定任何工具，按工作台工具目录顺序显示，不支持拖拽排序或队列级收藏。
- 偏好按 YuanHub 登录账号保存在当前浏览器；同账号跨设备/浏览器不自动同步，已打开的其他标签页不实时同步。清除浏览器站点数据会清除设置。
- 快捷入口只展示当前已获授权且已开放的工具。权限加载或失败时隐藏；撤权、退出、切换账号后不沿用其他身份的可见入口。恢复权限后原固定项可再次出现。
- 存储不可用时显示提示，仍可在本次会话固定/取消；刷新后可能丢失。
- 打开已固定管理页时高亮具体入口；未固定的管理页及管理子页（如成就投稿审核）仍归属「管理工作台」。星石识别核对仍归属星石页面。现有路由和服务端鉴权不变。
