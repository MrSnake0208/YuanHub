# 通知中心

- 通知用于反馈回复、处理状态及内测资格提醒；完整沟通记录在「我的反馈」。
- 「全部」与「未读」使用不同空状态；未读为空可切回全部，首次为空可进入我的反馈。
- 每条有关联目标的通知提供可键盘访问的查看链接；标为已读仍是独立操作。
- 新生成的交接通知直接展示操作人、交接双方或目标程序板块及人员，以及反馈摘要和交接说明；转交、接手、交回和撤回使用各自文案。双方和操作人均可在通知中心查看，重合身份只收一条。
- 摘要和说明保留换行，完整显示服务端提供的有界正文，不再限为两行；内容以通知生成时的快照为准，历史通知不回填。
- 站内通知保留最近 90 天，保留期限显示在列表附近。
- 批量标记期间禁用重复操作，失败保留重试入口。
- 「全部」模式加载多页后，单条或全部已读只更新已加载项目，不替换累计列表；未读角标复用共享服务端刷新，不独立递减。
- 「未读」模式已读成功后回第一页重建结果，防止页边界移动导致跳项；标记期间暂停筛选、分页与其它标记操作。
- 标记失败保留原状态；标记成功但列表刷新失败明确提示「已标记成功，但通知刷新失败」，重试仅刷新，不重复标记。刷新失败保留尚未标记的已加载通知，不用失败结果展示已清空的成功空态。
- 筛选切换、用户退出/切换、组件卸载会使旧列表请求失效；旧成功、错误和结束回调不覆盖当前列表、角标或加载状态。

## 反馈实时提醒

- 登录后由 App 管理私人通知 SSE，退出或切换用户时关闭旧连接、清空卡片与内存基线。请求通过 Authorization Bearer 头鉴权，不依赖内测资格或游戏子账号，不把 JWT 放入 URL。
- 首次成功加载未读通知建立静默历史基线。连接建立、重连、通知事件及页面恢复可见时，通过原未读接口校准共享角标；通知中心同步刷新并保留已加载页数，标记或分页期间延后实时列表刷新。
- 只为新 `FEEDBACK_REPLY` / `FEEDBACK_MESSAGE_FROM_REPORTER` 显示卡片。管理员消息进入 `/feedback/manage?id=...`，管理员回复进入 `/feedback?id=...`，仍由现有路由及详情接口校验权限。打开对应详情时优先刷新消息并走原已读逻辑，保留回复草稿与输入焦点。
- 卡片与账号事件共用浮层堆叠：桌面右上角，手机位于底部操作栏及安全区之上。最多保留三张反馈卡，约 5 秒消失，鼠标悬停或键盘焦点进入时暂停；关闭不等于已读，未处理内容仍可从通知中心查看。
- 在「通知中心 → 回复提示音」切换声音，初始开启，偏好仅保存在本浏览器。首次可信点击/按键后才尝试解锁音频；浏览器拒绝时静默，不弹权限框，不补播历史声音。短音约 0.24 秒，低音量；同一用户 3 秒内最多响一次。
- 标签页使用通知 ID 去重，后台页延后展示。支持 Web Locks 且 localStorage 可用时跨标签串行认领，只保存有界 ID 列表和声音冷却时间，不保存消息正文。老浏览器不支持 Web Locks、存储被禁用或不同浏览器/设备时，不能保证跨页/跨设备完全去重。
- SSE 健康时每 120 秒做一次补偿查询；断线时每 30 秒查询。15 秒心跳，45 秒无数据则重连，重试间隔 1–15 秒；服务端约 5 分钟轮换连接以重验 JWT。页面后台冻结、浏览器限流、网络及音频策略可能延迟提醒；不提供离线 Web Push。

人工验收：在 390px 手机、768px 中间态和 1440px 桌面，先点击页面解锁音频，再从另一账号回复/追加反馈；检查卡片、一次短音、查看入口、详情草稿和账号事件同时到达的堆叠。再关闭声音、开第二标签页、退出重登，确认历史不逐条提醒。实际布局、触控及浏览器音频策略须由用户验收。
