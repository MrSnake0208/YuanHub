# 通知中心

- 通知用于反馈回复、处理状态及内测资格提醒；完整沟通记录在「我的反馈」。
- 「全部」与「未读」使用不同空状态；未读为空可切回全部，首次为空可进入我的反馈。
- 每条有关联目标的通知提供可键盘访问的查看链接；标为已读仍是独立操作。
- 新生成的交接通知直接展示操作人、交接双方或目标程序板块及人员，以及反馈摘要和交接说明；转交、接手、交回和撤回使用各自文案。双方和操作人均可在通知中心查看，重合身份只收一条。
- 摘要和说明保留换行，完整显示服务端提供的有界正文，不再限为两行；内容以通知生成时的快照为准，历史通知不回填。
- 站内通知保留最近 90 天，保留期限显示在列表附近。
- 批量标记期间禁用重复操作，失败保留重试入口。
