# 账号与连接码

页面、导航和手机标题统一为账号与连接码。本站账号用于登录，游戏账号是 YuanHub 中的数据存档；每条连接码只绑定其中一个游戏账号。

首屏「连接 MaaYuan」打开现有授权表单并滚动聚焦；没有游戏账号则引导到统一的游戏账号管理区，资格和创建权限维持原有规则。

连接表单默认采用当前游戏账号；默认选择随当前账号更新，用户主动改选后保留该绑定目标，直到目标账号不再可用。MaaYuan与高级连接选项均展示“游戏 · 账号名称”，提交前的说明明确数据保存对象；切换连接目标不会更改全站当前账号。生成请求期间不改变绑定对象；登录用户切换后不展示旧用户的晚到凭证。

账号创建表单按管理组件自身宽度切换堆叠、两列和三列，说明始终独占一行。按钮至少44px高，文案不逐字换行，长账号名不撑坏卡片。创建失败保留输入，重试期间重复提交不增加在途请求。已有账号仍按原结构展示，本轮未折叠新建区。

「已授权 MaaYuan」只表示权限符合要求，不表示收到采集数据。创建后按说明填写并运行任务，再切换至绑定游戏账号的库存或密探页确认数据。页面不显示未经验证的同步成功时间。星石自动采集接入中的限制在能力介绍中提前说明。

开发环境 `/user/profile` 的 HTML 页面导航交给 SPA，JSON API、其他 `/user` 接口继续由 Vite 代理到后端；代理的目标地址和 Origin 处理保持原有配置。
