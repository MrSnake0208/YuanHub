# 反馈中心

首次没有工单时可提交第一条反馈或查看反馈广场；筛选无结果可清除条件。列表优先显示标题，私人列表的编号折叠展示。

新建反馈默认仅私下沟通，无需标题。用户主动勾选「允许管理员整理到反馈广场」后才显示必填标题和相似反馈；勾选不会自动发布。取消勾选保留标题草稿，但不提交隐藏标题、不继续相似检索。公开授权与附加浏览器/操作系统/IP 信息的选择相互独立。

管理员只能发布明确授权的反馈，共享发布面板显示授权状态；未授权时不能保存公开内容，仍可取消已有公开。缺少授权字段的历史反馈按未授权处理，不由管理员补授权；已经公开的历史内容不会自动撤下。

相似反馈详情在新标签页打开，支持相似反馈也保留标题、正文和附件草稿。关闭未提交的草稿仍需确认。表单支持 Tab 焦点限制、Esc 关闭及关闭后返回入口。

「标记完成」表示问题已解决并结案，不能继续追加消息；确认框会说明这一后果。提交成功后说明回复将通过站内通知送达。
