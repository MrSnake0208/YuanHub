# 反馈中心

反馈广场、我的反馈、反馈工作台和权限配置使用统一的「反馈中心」标题与紧凑页头；浏览器和手机顶部标题同时标明当前分区。内部导航按上述顺序排列，工作台与权限配置仍按账号权限显示，切换页面只改变当前选中项与内容。全站「管理工作台」位于内部导航之外的辅助区域，每页只保留一个入口；手机端位于导航下方。各分区保留独立路由、刷新直达与浏览器返回能力。

首次没有工单时可提交第一条反馈或查看反馈广场；筛选无结果可清除条件。列表优先显示标题，私人列表的编号折叠展示。

反馈广场允许游客浏览。登录后，广场列表、公开详情和相似反馈会根据服务端的本人支持记录恢复「已支持」，刷新或重新进入后仍保留；支持总数面向所有人显示，本人状态随登录用户变化。

新建反馈默认仅私下沟通，无需标题。用户主动勾选「允许管理员整理到反馈广场」后才显示必填标题和相似反馈；勾选不会自动发布。取消勾选保留标题草稿，但不提交隐藏标题、不继续相似检索。公开授权与附加浏览器/操作系统/IP 信息的选择相互独立。

管理员只能发布明确授权的反馈，共享发布面板显示授权状态；未授权时不能保存公开内容，仍可取消已有公开。缺少授权字段的历史反馈按未授权处理，不由管理员补授权；已经公开的历史内容不会自动撤下。

相似反馈详情在新标签页打开，支持相似反馈也保留标题、正文和附件草稿。关闭未提交的草稿仍需确认。表单支持 Tab 焦点限制、Esc 关闭及关闭后返回入口。

「标记完成」表示问题已解决并结案，不能继续追加消息；确认框会说明这一后果。提交成功后说明回复将通过站内通知送达。

管理员工作台按当前搜索、类型和负责板块显示各队列总数，数量来自服务端分页总数，失败时显示「—」和重试提示。运营可进入「已交回运营」队列；「需我回复」只包含本人负责、处理中且用户最后一条消息尚未被管理员回复的工单。默认按最早提交排序，也可选择最近更新或最新提交；最早提交不等同于用户等待回复时长。

回复文字、附件和流转说明在取消、关闭详情、切换工单/筛选、离开路由及刷新页面前受草稿保护。拒绝放弃时保留正文、附件和原筛选值。回复表单打开后聚焦输入框，详情、发布、合并与权限弹窗限制 Tab 焦点，Esc 关闭最上层，关闭后返回入口。处理记录仍位于原有「工单流转」菜单，入口条件不变。

管理员回复框提供「插入当前版本」按钮，旁边显示当前页面加载的前端产品版本（与侧边栏一致）。点击后在光标位置插入版本号，选中文字时替换所选内容，并返回输入框继续编辑；例如「该功能已于 v0.0.1-beta.15 实现」。插入不会自动发送，不使用用户提交反馈时的旧版本；插入后超过 1000 字符会提示并保留原文，发送期间按钮不可用。更新发布后应先刷新页面，再插入新版本。

完成、驳回和重新打开使用明确的确认文案，成功后显示结果并保留筛选、排序和有效页码；原页消失时回退至最后有效页。管理列表优先显示两行摘要、待办状态、负责人及更新时间，编号折叠后可复制；手机列表保留状态和进入详情的操作。

「全部管理范围已读」与列表筛选分开呈现，确认框说明数量及包含筛选之外的工单，只更新阅读状态，不结案。「反馈类型」使用与反馈广场相同的定义；类型修改同时影响内部和公开筛选，内部结案与广场进度分别更新。合并弹窗展示来源及主反馈，搜索或来源改变立即清除旧选择，旧请求不能覆盖最新结果。

权限页优先展示运营/程序岗位与负责板块；通知接收及兼容管理授权放在折叠区域，预览和保存仍保留全部授权。通知、兼容管理和工作台岗位分别生效，不自动授予岗位或覆盖岗位板块。
