# 发展规划

## 当前公开页面（2026-10-25）

`/roadmap` 是独立的只读发展规划页，游客与登录用户均可通过桌面侧栏或手机抽屉中的「更多 → 发展规划」进入。

页面沿用站点侧栏、纸张背景、主题与值守页头，正文为暖白底板、三组内容与局部插画：

| 主题 | 规划方向 |
| --- | --- |
| 记录与陪伴 | 成就系统、羁绊系统、信赖值 & 传闻 |
| 计算与规划 | 密探面板自动计算、入战数据计算 |
| 随时查看 | 安卓端小组件 |

这六项由项目维护者提供，不推断开发完成度、排期或具体功能范围。面板计算只是入战数据计算的基础，入战规则与所需数据仍待确认；安卓小组件展示内容待定。已有成就/羁绊入口不等于上述规划已全部完成，页面不改变其权限或开放状态。

规划文案维护于 `src/pages/roadmap/index.vue`，不调用历史开发目标 API，也不新增管理端或写入数据库。「分享你的想法」沿用 `/feedback?new=1&type=FEATURE`，游客按现有登录守卫回跳。正式发布情况以更新日志为准。

插画使用官方内置 imagegen 生成的透明 3×2 图集 `public/roadmap/illustrations.png`，顺序为奖章、双结、信封、属性纸张、双剑、小组件；作为装饰 CSS 背景，文字独立渲染。双端布局分别由 `roadmapDesktop.css` / `roadmapMobile.css` 持有，配色使用现有主题变量。素材缺失不影响六项文本和链接。

### 人工验收（待用户执行）

1. 桌面「更多 → 发展规划」：侧栏、背景、值守页头沿用现有框架，六项规划完整、图片不串格，分享建议与更新日志可进入。
2. 手机打开同一入口：内容纵向排列，计算依赖箭头向下，没有横向溢出；键盘焦点与返回入口清晰。参考 320 / 390 / 430 / 768 / 1024 / 1440px 及 1080/1081px 导航临界宽度。
3. 切换浅色/深色，文字、分隔线与插画可辨认；未登录提交建议需要登录，成功登录后保留新建议参数。
