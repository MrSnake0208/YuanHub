# BOX 图片分享

在「我的密探 → 分享 BOX → 图片分享」生成图片，不需要开启链接分享。原有公开范围、链接复制和撤销操作在「链接分享」中保留。

- 默认导出养成总览的当前筛选结果与顺序，可切换为全部已拥有；只使用已保存的养成和配装，未保存的卡片草稿不会进入图片。
- 图片固定浅色、PNG 宽 1440px、每行最多五张。CSS 布局宽 1038px（五张 190px 卡片、四个 10px 间距、两侧各 24px 留白），按 1440/1038 倍渲染，避免为凑输出分辨率而横向拉宽卡片。导出网格显式覆盖总览的自动列数规则。`OperatorBoxImageSheet.vue` 调用 `operatorLedgerCardVersionClass()`，正确保留 V3 继承 V2 的约定，使用总览相同的 V1/V2/V3 桌面样式源和 `ShareCardStats`；沿用卡头、左右核心养成/攻血面板及双命盘的 DOM 分区，不独立定义立绘、姓名、卡片边框或命盘配色。
- 保留立绘、竖排姓名、属性/职业、原位置的只读养成状态、等级、修为、化极星数/节点/觉醒、攻击/生命、攻血奇闻当前值及真实上限、两套命盘全部已配词条及品质色。奇闻直接取已保存的 `combatStats.oddities.attack/hp`，保留零值，正上限达到时沿用总览绿色。未知值保持「—」或「化极待确认」，不虚构上限。不请求、展示历程，也不添加空命盘说明。
- 化极沿用 `operatorHuaji()` / `operatorHuajiLabel()`，兼容历史 `starLevel/star_level`，不把历史字段当作额外的独立星级。觉醒卡与原版一样显示「已觉醒」，完整化极标签保留在无障碍说明中。攻血继续使用原有配装及后端面板结果，保留装备和奇闻的计算影响，不修改计算公式；未保存草稿不进入图片。
- 不包含账号名、UID、备忘、自定义标签、养成目标、私人命盘名称、星石装备槽、特别关注、置顶及编辑/保存/取消/提升/命盘添加等操作。小徽章的材料库存/需求比例属于提升操作，也随按钮移除。只读文本和 `output` 替换输入控件，去掉操作列占位，保留原面板细边框、数字层级和底部分隔；共享奇闻样式只扩展为同时适配 `input/output`，原总览输入框规则不变。
- `html2canvas` 的兼容处理只发生在导出副本：按浏览器计算结果转换现代颜色语法，刷新桌面立绘渐变，按实际排好的字形坐标绘制竖排文字。手机生成也使用 1440px 的副本视口触发桌面规则，在 1038px 布局内测量后按同一倍率截取。支持 Canvas 滤镜的浏览器会先将原立绘的 `saturate(.88)` 烘焙到副本图像，避免 `html2canvas` 忽略滤镜。颜色、渐变和竖排适配的真实浏览器表现仍需人工确认；不支持 Canvas 滤镜的浏览器仍可能存在饱和度差异。
- 默认每张最多 30 位（五列六行），按完整卡片分图。105 位生成 30＋30＋30＋15 四张；也可生成完整长图。每张标明总人数、页数、序号范围与生成时间。
- 生成后预览并逐张保存 PNG；手机可长按预览图保存。逐张保存避免浏览器连续下载限制。生成失败保留已完成的分图，可重新生成；立绘/字体准备超时会报错，不输出缺图快照。

图片在本机浏览器生成，不上传图片、不写入账号或公开权限。关闭弹窗、切换分享方式、切换账号/游戏及离开页面后释放生成结果；异步旧结果不会出现在新账号。分享出去的图片不会随云端更新或撤销，发送前请核对预览。

完整长图按渲染倍率换算后，超过 16,000,000 像素或高度超过 16,384 像素时提示使用分段；设备内存不足也可能导致生成失败。分段和长图使用完全相同的卡片模板、列宽和倍率，仅页内人数不同。分段逐张渲染，及时释放 canvas 内存。聊天软件压缩清晰度、手机保存及真实视觉布局由用户人工验收。

静态对照使用用户截图中的徐庶和孙尚香字段，覆盖两字/三字姓名、5 星/4 星 5 节点、奇闻满值/未满值、双命盘四词条/六词条及品质色。长姓名使用源码中的陈登·黍王、史子眇·赴烛真实身份和续行结构，未提供的账号养成数据保持未知。`behavior/operatorBoxImageSheet.spec.js` 对照总览与导出分区的结构层级、共用样式来源及操作区域删除；这些静态证据不能证明真实像素一致。

人工验收：先导出截图中的徐庶、孙尚香，与总览对照立绘裁切、姓名/属性/职业和状态位置、左右面板分隔、星数/节点、奇闻当前值/上限和全部命盘词条，确认每行最多五张、历程及操作已移除。再检查已拥有的长姓名及不同化极节点卡片，在桌面及手机各保存分段图和长图，确认同一卡片比例与排版一致、PNG 宽 1440px。总览中的关注、置顶、星石、备忘和完整编辑应仍可使用。
