# BOX 图片分享

从「分享 BOX」打开弹窗默认进入「链接分享」，可切换右侧「图片分享」。在「我的密探 → 分享 BOX → 图片分享」生成图片，无需开启链接分享。图片用于向代打展示拥有的角色与练度；图片本身不判断是否能通关。

- 从「养成总览 → 批量选择」勾选密探后，点击同一操作栏的「导出图片（N）」直接进入图片分享，默认导出「已选密探」。原有批量标注操作保留，导出不要求添加标注或保存组合。有效选择仅包含当前筛选内勾选的密探，按当前列表顺序导出；关闭或生成失败保留勾选，退出批量或切换账号/游戏清空选择。再次从批量入口打开会恢复「已选密探」范围，空选择不会退回全部导出。
- 普通图片分享默认使用当前筛选结果和顺序，可切换全部已拥有；有勾选时也可选择「已选密探」。仅导出已保存的养成与配装，未保存草稿不进入图片。
- 使用独立的浅纸底三列卡片：真实立绘、竖排姓名、属性/职业，突出化极星数、节点与觉醒；等级修为并排，攻击生命对齐，下方保留真实奇闻当前值/上限和两套命盘全部已配词条及品质色。未知值保留「—」或「化极待确认」，空命盘显示「未配置」，长词条自然换行。
- 不显示重复的养成状态、编辑控件、账号名、UID、备注、自定义标签、目标、私人命盘名称、星石装备槽、关注与置顶；装备和奇闻对攻血的计算影响仍然保留。没有新增数据请求或修改计算公式。
- 导出布局固定 1080px，PNG 宽 1440px；手机和桌面均使用同一模板，不依赖总览卡片宽度或皮肤版本。每张最多九位（三列三行），105 位生成十二张，末张六位。每张标明总数、页码、序号范围及生成时间。
- 生成前提示完整长图预计容纳约 51 位（非保证上限，词条换行会减少容量）；当前选择超过 51 位时直接显示所需分段张数并建议分段，容量说明位于长图按钮下方，仍允许尝试完整长图。
- 1–9 位只显示「生成图片」，生成一张三列图片；10 位及以上显示分段图与完整长图两个入口。
- 超过九位可生成完整长图，使用相同三列排版。渲染后预计超过 16,000,000 像素或高度 16,384px 时提示改用分段；设备内存不足仍可能导致失败。逐张渲染并释放 canvas，失败保留已完成分图。

卡片使用实体细边框和明确的浅白数据底色，不使用内阴影。立绘保持原色、小幅放大裁切，仅在右侧和底部边缘使用同色透明渐变，避免大范围遮罩冲淡人物。

生成后预览并逐张保存 PNG；手机可长按保存。立绘/字体准备超时会报错，不输出缺图快照。截图克隆阶段排除无关页面分支，只保留导出区域、祖先容器和 head 样式/字体资源。独立模板使用普通 RGB 颜色，不再逐节点扫描旧总览的滤镜、现代颜色与虚线；仍保留立绘渐变和竖排字形定位兼容处理。后续若引入现代颜色、滤镜或重复渐变，需同步确认导出支持。

图片在本机浏览器生成，不上传图片、不写入账号或公开权限。关闭弹窗、切换分享方式、账号/游戏及离开页面会释放结果，过期异步结果不会出现在新账号。已经发送的图片不会随云端更新或撤销。

人工验收：在桌面和手机各生成一张，确认三列、立绘、竖排长姓名、化极与双命盘完整；对照已保存数据核对攻血、零值和未知值；检查第九/十位分页与末页人数，保存原 PNG 后以 100% 查看文字，再确认聊天软件压缩后的可读性。代码和组件检查不等于真实 PNG 视觉验收。
