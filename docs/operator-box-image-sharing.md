# BOX 图片分享

从「分享 BOX」打开弹窗默认进入「链接分享」，可切换右侧「图片分享」。在「我的密探 → 分享 BOX → 图片分享」生成图片，无需开启链接分享。图片用于向代打展示拥有的角色与练度；图片本身不判断是否能通关。

- 从「养成总览 → 批量选择」勾选密探后，点击同一操作栏的「导出图片（N）」直接进入图片分享，默认导出「已选密探」。原有批量标注操作保留，导出不要求添加标注或保存组合。有效选择仅包含当前筛选内勾选的密探，按当前列表顺序导出；关闭或生成失败保留勾选，退出批量或切换账号/游戏清空选择。再次从批量入口打开会恢复「已选密探」范围，空选择不会退回全部导出。
- 普通图片分享默认使用当前筛选结果和顺序，可切换全部已拥有；有勾选时也可选择「已选密探」。仅导出已保存的养成与配装，未保存草稿不进入图片。
- 使用独立的暖纸金边收藏卡式五列模板：真实立绘、单列竖排姓名、属性/职业，突出化极星数、节点与觉醒，星级用对应数量的香槟金实心星表示，不补空星、不重复显示数字星数，节点与觉醒仍用文字显示，未知化极不显示星星；化极与并排的等级修为置于立绘下缘的弧形纸面内，以细金线分隔养成和战斗数据；等级、修为各自将标签与数字作为一组居中，按垂直中心对齐，攻击生命分列并以浅竖线分隔，图标标题与主数值各自在列内居中，主数值单独成行；不展示奇闻标签及当前值/上限，攻血下方直接衔接两套命盘全部已配词条及品质色。未知值保留「—」或「化极待确认」，空命盘显示「—」（语义为未配置）；命盘一、命盘二上下分区，每区上方显示完整标签和细分隔线，下方固定三列等宽词条格，文字居中，短词条或缺少词条不改变列宽，缺少的词条用浅边框空格占位，词条行占满内容宽度，不再占用左侧标签列。常规词条使用统一字号；超长词条在导出克隆中仅等比缩小文字，保留全文和字形比例，不换行、不省略，底色格宽保持一致。
- 不显示重复的养成状态、编辑控件、账号名、UID、备注、自定义标签、目标、私人命盘名称、星石装备槽、关注与置顶；装备和奇闻对攻血的计算影响仍然保留。没有新增数据请求或修改计算公式。
- 导出布局固定 1080px，PNG 宽仍为 1440px，不因增加列数加宽；手机和桌面均使用同一模板，不依赖总览卡片宽度或皮肤版本。每张最多十五位（五列三行），105 位生成七张。每张标明总数、页码、序号范围及生成时间。
- 生成前显示所需分段张数；完整长图的容量取决于人数与设备内存，不再显示旧三列布局的约 51 位估计值。
- 1–15 位只显示「生成图片」，生成一张五列图片；16 位及以上显示分段图与完整长图两个入口。
- 超过十五位可生成完整长图，使用相同五列排版，30 位为六行，末行不足五位时靠左。渲染后预计超过 16,000,000 像素或高度 16,384px 时提示改用分段；设备内存不足仍可能导致失败。逐张渲染并释放 canvas，失败保留已完成分图。

导出数据文字沿用密探总览字体：普通中文、职业、化极正文、命盘标签与词条使用 `--font-b`（PingFang SC → Hiragino Sans GB → Microsoft YaHei → sans-serif），等级、修为和攻血使用 `--font-d`（Archivo 优先，系统黑体回退）。等级、修为及攻血采用 700 字重，按 B 方案降低攻血的视觉重量；命盘标签为 500，命盘词条为 600 字重，字号 11px、格高 28px，命盘标签在词条上方完整横排；词条列间距 4px，两套命盘分区间距 9px，底部留出 18px，避免词条贴近折角边框。标题与姓名使用总览同款 `--font-s`（Noto Serif SC 优先），900 字重；副标题为 600。保留五列导出宽度，标题 38px，姓名两字 28px、三字 26px。生成前及截图克隆阶段显式等待思源宋体和 Archivo 对应字重，并传入导出全文加载中文字体分片；加载失败提示重试，不静默输出回退字体。字体复用站点现有资源，不再加载导出专用思源黑体。系统正文黑体仍取决于设备。超长命盘仍按格宽等比缩小，避免截断。

分享图采用 B 方案的暖纸金边收藏卡：细金色外框、内侧折角装饰、右上暖白姓名签，属性/职业放在左上独立的窄暖白底签。立绘区域高 280px，数据纸面在 264px 处开始叠入，以弧形上缘连接人物与数据；化极与等级修为共用纸色背景，以细金线分隔养成与战斗数据，不再使用独立浅黄练度框。页头仅保留标题、副标题与分页信息，不增加装饰文字印章。页面顶部有淡竹叶与飞鸟，底部有淡山形装饰及细金分隔线。装饰及星星 SVG 均来自本仓库 `public/assets/operator-box/`，随普通图片一起等待加载；不使用滤镜、mask 或 clip-path。星星使用 `star.svg` 的浅香槟金渐变、细描边和高光切面，单颗 15px、间距 2px；读屏标签保留真实星数。竹山装饰位于纸色背景上、内容下，避免负层级使其在截图中丢失。

立绘复用仓库透明原图，不使用效果图中 AI 重绘的人物。浅衬底沿用原有属性与角色配色，仅为装饰，不改变属性图标含义；原色保留，只在底部渐变到暖纸色。姓名签保护文字对比度，不再对立绘右侧整片刷白。卡片不因命盘词条长度增加高度，不裁切数据。收藏卡比旧紧凑版更高，完整长图仍按实际像素面积检查容量，不保证旧版相同人数仍能放入一张长图。

生成后预览并逐张保存 PNG；手机可长按保存。立绘/字体准备超时会报错，不输出缺图快照。截图克隆阶段排除无关页面分支，只保留导出区域、祖先容器和 head 样式/字体资源。独立模板使用 `box-image-*` 类名与普通 RGB 颜色，避免总览的全局 `ledger-*` 样式和主题污染导出；仍保留立绘渐变和竖排字形定位兼容处理。后续若引入现代颜色、滤镜或重复渐变，需同步确认导出支持。

图片在本机浏览器生成，不上传图片、不写入账号或公开权限。关闭弹窗、切换分享方式、账号/游戏及离开页面会释放结果，过期异步结果不会出现在新账号。已经发送的图片不会随云端更新或撤销。

人工验收：在桌面和手机各生成一张，确认五列金边卡、折角与淡竹山装饰可见、立绘不遮挡脸部、姓名签与职业不相撞、弧形纸面衔接正常、竖排长姓名及化极与双命盘完整；重点确认一至五星数量、五星觉醒和零节点不挤压，未知化极不出现星星；对照已保存数据核对攻血、零值和未知值；检查第十五/十六位分页与末页人数，再生成含 30 位及长命盘词条的完整长图，检查行间距与内容无截断。保存原 PNG 后确认仍宽 1440px，以 100% 查看文字，再确认聊天软件压缩后的可读性。代码和组件检查不等于真实 PNG 视觉验收。
