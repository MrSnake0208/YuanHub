# BOX 图片分享

在「我的密探 → 分享 BOX → 图片分享」生成图片，不需要开启链接分享。原有公开范围、链接复制和撤销操作在「链接分享」中保留。

- 默认导出养成总览的当前筛选结果与顺序，可切换为全部已拥有；只使用已保存的养成和配装，未保存的卡片草稿不会进入图片。
- 图片固定浅色、五列卡片，沿用现有立绘、竖排姓名、属性/职业、等级、修为、化极/觉醒、攻血和两套命盘。未知面板显示「—」，未配置命盘明确标注。
- 导出宽度固定为 1440px，采用养成总览 V3 的只读展示结构：全宽立绘保留原比例、234px 高度及定位，右上角竖排姓名与属性/职业；下方等级、修为与攻血左右对照，化极独立完整展示，再按「命盘一／命盘二」分组。长姓名按四字一列排布，不缩小字号或截断；命盘沿用总览的词条简称和金、紫、蓝品质底色，长词条自然换行，同一网格行卡片等高，不固定高度裁切内容。
- 等级来自已保存的 `level`，不虚构等级上限；修为来自 `elite`，未知显示「—」而不是零。化极使用 `operatorHuajiLabel()`，以 `huaji` 为准并兼容 `starLevel/star_level`；后者是历史化极字段（SP 有对应换算），不是额外的独立星级。保留实际星数 `★`、节点及已有觉醒文字，未知化极仍显示「化极待确认」。
- 攻击与生命沿用原有已保存快照和面板计算结果，保留装备星石与奇闻的计算影响；图片不展示奇闻细项及自动计算、手动修正等来源文字，不另算攻血。化极历程按钮本身是另行读取/补录日期的入口，不放入静态图片；当前星数、节点和觉醒结果完整保留，不额外读取历程日期。
- 不包含账号名、UID、备注、自定义标签、养成目标、私人命盘名称、星石装备槽、特别关注星标、置顶、状态菜单、编辑/保存/提升/命盘添加按钮或分享链接。导出 DOM 仅含展示元素，养成总览的原有控件与数据不受影响。
- 默认每张最多 30 位（五列六行），按完整卡片分图。105 位生成 30＋30＋30＋15 四张；也可生成完整长图。每张标明总人数、页数、序号范围与生成时间。
- 生成后预览并逐张保存 PNG；手机可长按预览图保存。逐张保存避免浏览器连续下载限制。生成失败保留已完成的分图，可重新生成；立绘/字体准备超时会报错，不输出缺图快照。

图片在本机浏览器生成，不上传图片、不写入账号或公开权限。关闭弹窗、切换分享方式、切换账号/游戏及离开页面后释放生成结果；异步旧结果不会出现在新账号。分享出去的图片不会随云端更新或撤销，发送前请核对预览。

完整长图超过 16,000,000 像素或高度超过 16,384 像素时提示使用分段；设备内存不足也可能导致生成失败。分段逐张渲染，及时释放 canvas 内存。聊天软件压缩清晰度、手机保存及真实视觉布局由用户人工验收。
