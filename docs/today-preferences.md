# 今日一览模块设置与跨设备同步

今日一览顶部「自定义首页」打开设置。电脑布局使用紧凑对话框，手机布局使用底部 Sheet；以现有 `min-width: 768px` 为分界，不使用 User-Agent。可在任一设备编辑电脑端或手机端。切换配置标签保留两端草稿，保存只提交当前标签；关闭、Escape、遮罩或离开路由时先确认放弃未保存修改。保存期间禁止关闭。

五个稳定模块 ID：`highlights`（今日重点）、`checklist`（活动待办）、`activities`（游戏活动）、`training`（我的养成计划）、`private_items`（私人安排）。没有偏好时全部默认开启，仍遵守原有功能开关、登录/游戏账号与空数据规则。新模块只要不在隐藏列表就默认显示。可全部隐藏，导航、账号、自定义入口、建档与错误提示继续保留；恢复默认后点击保存即可恢复。

隐藏只影响首页展示，不删除数据、不取消订阅、不改变站内提醒。页面仍保留原有业务控制器，避免切换布局/偏好时重建业务状态；隐藏模块的数据读取策略沿用现有实现。首页的 `TodaySubscriptionSummary` 与 `TodayPrivateItems` 各保留一个数据实例，并向页面发布带用户、子账号和游戏标识的只读快照。独立的 `TodayHighlights` 展示合并后的重点，位置仍在工作台上方；隐藏活动待办或私人安排不影响重点，隐藏重点不影响其它模块或全站私人提醒弹窗。首页不增加重复请求，偏好 API 与 schema 保持不变。综合提醒规则与验收见 [今日重点](today-highlights.md)。

## API 与持久化

需要 YuanHub JWT；所有者只来自 `AuthenticationHelper.requireUserId()`，与游戏子账号无关。

| 操作 | 路径 | 语义 |
| --- | --- | --- |
| GET | `/v1/today/preferences/{mode}` | 只读；缺失返回默认 `version: 0`，不会写入数据库 |
| PUT | `/v1/today/preferences/{mode}` | 以 `expected_version` 原子保存该端配置，成功版本加一 |

`mode` 只允许 `desktop` / `mobile`。PUT JSON：

```json
{"schema_version":1,"expected_version":0,"hidden_modules":["private_items"]}
```

统一 `ApiResult` 成功数据：

```json
{"layout_mode":"desktop","schema_version":1,"version":1,"hidden_modules":["private_items"],"updated_at":"2026-10-16T00:00:00Z"}
```

拒绝未知字段（包括 `user_id`、`account_id`）、未知/重复模块、错误类型、负数或非安全整数版本；JSON 请求体上限 4096 字节，包括无 Content-Length 的流式请求。格式错误返回 422，过大返回 413，同模式过期修订返回真实 HTTP 409。成功响应 `Cache-Control: no-store`。

集合为 Hub 数据源下的 `hub_user_today_preferences`，字段为 `_id`、`userId`、`layoutMode`、`hiddenModules`、`schemaVersion`、`version`、`updatedAt`。`_id` 使用用户 UTF-8 的 URL-safe Base64 加 `:` 和模式，借助 Mongo 自带 `_id` 唯一索引避免首次建档竞争；后续按用户、模式、版本执行 `findAndModify` CAS。不改 `maa_user`，无需预建索引、迁移或多文档事务。配置格式版本和各端修订版本彼此独立。

## 同步与失败恢复

`useTodayPreferences` 是首页唯一偏好控制器。登录身份确定后预取两端，切换子账号不重取；切换响应式布局直接选择对应快照，不重复请求。首次读取完成前显示加载提示，避免先展示默认模块再隐藏。读取失败保留明确错误和重试；后台读取失败保留已有成功快照。

页面重新可见、pageshow、窗口重新获焦时，两端按 30 秒新鲜度检查并合并并发读取，不设轮询。打开设置也按需检查。保存成功立即采用服务器结果并提示已保存；失败保留草稿且不提示成功。冲突后禁止盲目重试，需明确确认「读取最新设置」替换该端草稿，核对后重新编辑保存；另一端草稿保留。远端刷新不会覆盖未保存草稿或其基准修订。

身份代次和卸载标记阻断旧用户/旧会话迟到结果；API 携带 `expectedUserId` 防止 401 刷新重放使用另一个用户身份。登出立即清空快照和草稿。服务器为同步权威，不使用本地持久缓存。

## 部署与回滚

必须先部署后端，再部署前端。旧前端不会调用新接口，新后端与其兼容。新前端连接旧后端会显示设置读取错误并暂不展示偏好控制的模块，不能将 404 当成默认设置；回滚后端时先回滚前端。回滚前端不会删除已有服务器偏好。两端分别有独立修订，不会互相产生保存冲突。

## 最小验证与人工验收

风险 **L3**：新增认证 API、用户级持久化、乐观锁及共享前端状态。非浏览器组件/单元/契约测试已新增；数据库竞争测试使用 `TestMongo` 自有可抛弃容器，禁止连接开发或生产库。

```bash
# 由用户执行，真实Mongo唯一性/CAS与跨用户、双端隔离
cd BackEndV3-Share
./gradlew integrationTest --tests '*TodayPreferencesMongoTest' --console=plain
```

真实浏览器视觉和触控尚未验证，人工验收：

1. 在电脑端（1440px）隐藏私人安排并保存，手机端（390px）隐藏养成计划并保存；刷新和另一台同类设备登录应读取各自配置，切游戏子账号不改变偏好。
2. 两端切换编辑、未保存关闭/返回，确认草稿保留或按确认放弃；全部隐藏后导航、账号、自定义入口和建档仍可用，恢复默认并保存可恢复模块。
3. 单独隐藏活动待办时，临期「今日重点」仍显示；反向隐藏重点时待办仍能勾选，站内提醒不变。
4. 两设备同时编辑同一端，第二次保存应提示冲突；明确读取最新、核对再保存。断网读取或保存应显示失败和重试，不得提示同步成功。
5. 在 320/390/768/1440px 及手机横屏检查入口、弹窗/Sheet、剩余模块收拢、原阅读顺序、Tab/Escape/焦点返回和底部安全区；保存或快速切换用户后不得出现上一用户偏好。
