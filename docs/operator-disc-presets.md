# 命盘快捷选择

命盘编辑器在“编辑当前命盘 / 编辑目标命盘”下方显示“常用命盘”，一盘、二盘使用同一组候选，不区分如鸢和代号鸢。每个密探最多三套完整组合，不足三套按实际数量展示。

点击整行“填入”会替换正在编辑对象的三项词条，仍可手动修改，点击原有保存按钮后生效。不会更改另一套组合、另一编辑对象、手动名称或命盘标记；实际命盘使用自动名称时随词条更新，目标命盘不改变名称。完全匹配（忽略词条顺序）显示“已匹配”。

填入后可撤销最近一次快捷填入，恢复原词条。手动修改词条、切换组合或当前/目标、切换密探后，旧撤销失效，避免覆盖后续输入。保存期间禁用填入与撤销。候选中的任一词条不在当前图鉴时整套隐藏；没有有效候选时保留原手动选择区域。

## 数据来源及维护

`src/data/operatorDiscPresets.json` 是 2026-10-22 本地快照的合并统计结果，包含 125 个密探、336 套预设，仅存密探 ID 和公共词条全名，不包含用户标识、账号标识、保存人数或用户自定义名称。

统计所有 `discLoadouts` 保存方案，一盘、二盘同等计入；同账号、同密探的相同组合只计一次，忽略词条顺序。不使用第一套命盘兼容字段 `discs` 作为选用或热度权重。只有恰好三个不重复且匹配快照图鉴的词条才参与排名。

两款游戏合并后按保存账号数降序；并列时按排序后的词条全名元组（Unicode 码点序）升序取前三，不为并列扩大数量，也不因低频或小样本擅自替换组合。高频仅表示保存习惯，不表示实战最优。更新数据时沿用此规则离线生成并复核，私有快照不得提交或成为运行时依赖；本功能不实时查询用户数据。

## 定向验证与人工验收

非浏览器验证：`npx --no-install vitest run behavior/operatorDiscPresets.spec.js behavior/operatorDiscTargets.spec.js`。

人工验收在手机约 390px、桌面约 1440px：进入密探编辑 → 命盘，分别在两套组合的当前/目标中填入预设；检查三词条完整换行、填入后可调整和撤销、手动名称与标记保留，保存重开仍为选中的组合。没有候选的密探继续手动选择。组件测试不能证明浏览器布局和触控体验。
