## 部分支持

Work V1 已有实际 HTTP 接口，MAAYUAN/YUANASSIST Adapter 仍存在未映射动作与未确认执行语义。MAAYUAN 目标结果不是完整 MaaFramework Pipeline；必须检查 `status/issues`，不得丢动作后包装成 exact。星石采集是临时私有中转，需用户在站内识别、核对后处理。

## 没有正式承诺

任意 Pipeline 通用转换、跨账号 Token、绕过 Beta 资格、在线协议管理后台及统一 API 速率服务均不属于 V1。历史规划或 Draft 不自动转为支持承诺；后续必须独立设计、实现并取得验证证据后再更新本中心。

## 后续任务建议：正式第三方应用授权

建议独立立项评估面向小程序、网站、App 和桌面软件的正式授权体系。本轮仅纠正接入说明，没有实现以下能力，也不承诺开放时间。

1. 应用注册与身份管理：登记开发者、应用、可信回调地址和目标平台，明确应用与用户连接的归属。
2. 用户授权流程：评估 OAuth 等标准方案、账号选择和最小 Scope 同意页，以及小程序和纯客户端的安全限制；不能仅用开发者凭据换取其他用户数据。
3. 凭据生命周期与撤销：评估短期访问凭据、续期和按应用撤销；区分本地断开、服务端撤销与已取得数据的清理。
4. 多用户与规模约束：验证跨用户隔离、重放/回调攻击、Beta 准入、配额和错误约定，再评估 500 人等规模的上线条件。
5. 独立交付与验收：另行设计 API 契约、迁移兼容、用户 UI 和安全验证，获确认后实施，不修改当前手动 Token 机制来冒充已完成授权体系。
