# 成就档案：使用范围与人工验收

页面为 `/achievement`，沿用现有导航、网站登录和全站游戏账号；不需要羁绊助手。生产 feature flag 关闭，普通 Vite 开发可见。真实目录目前代号鸢0条、如鸢0条，分类/常驻隐藏成就未核验；页面如实显示资料空缺，测试样例不会进入目录。当前可以验收账号上下文、真实后端读取、空目录/错误恢复及空备份；有条目的完整人工流程必须等待真实资料，不能把组件测试当作真实资料验收。

## 功能与记录口径

“待核对”是未确认，不等于“确认未完成”。关注、备注和进度独立；达到数值目标仅提醒核对。勾选完成后成功才改变集合，取消表示未完成，详情可恢复待核对；撤销恢复上一次操作之前的字段和真实已知日期。摘要按当前游戏有效目录统计，筛选数量另算，不宣称全游戏完成率。

页面单一数据控制器负责双端请求、草稿、权限及保存；互斥 PC/Mobile CSS 调整布局。列表最多50条，搜索名称/别名/条件/实际关联密探名，提供分类、三态、关注和隐藏属性筛选。手机低频筛选进入现有弹层。标题打开详情，独立控件完成和关注；剧透默认折叠。未保存草稿离开/切账号提醒，保存与导入期间阻止切换，迟到响应不覆盖新账号。

后端保存后，在另一个设备进入页面、刷新或合理重新激活读取，不实时推送、不离线假保存。版本冲突提示刷新，详情草稿保留；非浏览器测试不代表真实手机布局、触控或键盘表现已验收。

“更多 → 导入与导出”备份当前账号全部记录，包含移出目录的历史记录，不受筛选影响。仅 YuanHub 成就 JSON v1，1000条/1MiB。选择文件自动生成预览，默认保留冲突，采用文件也不以空备注擦除已有备注。未知 ID 须明确跳过；非法项整批拒绝。预览后变更账号/文件/策略/版本需重新核对，预览10分钟失效或后端重启后重做。文件源账号仅提示，不能取得其它账号权限。

权威目录维护、接口、JSON 格式及未来羁绊约束见后端 `BackEndV3-Share/docs/achievement-api.md`。没有可发布资料前不启用生产入口；不要把测试 fixture 移入运行时文件。

## 电脑和手机人工验收

复用正在运行的开发服务，打开 `/achievement`（电脑约1440px、手机约390px，补看320px窄屏）。不要为验收重复启动服务；若现有后端没有加载新实现、接口404，需要用户安排通过根目录 `./dev.sh` 更新服务，Agent 本轮未重启服务。

1. 当前可做：游客分别查看两款空目录，确认无私人记录；登录后切换已有游戏账号，查看目标游戏及空资料提示，刷新；无账号时沿用现有账号管理。错误时确认可重试且不显示假保存。
2. 当前可做：进入“更多 → 导入与导出”，下载空档案并预览；确认目标账号、数量和版本。预览不写入，跨游戏文件被拒绝，未知 ID 不会变成生产条目，文件超限明确拒绝。
3. 真实资料就绪后：搜索/筛选，完成、关注、备注和数值分别保存，刷新及另一设备重新读取；待核对不混入未完成，达标不自动完成，撤销恢复原状态。
4. 真实资料就绪后：明确选择本页少量条目，确认账号及数量再批量；导出后导入同一文件、重复导入、冲突保留/采用文件及未知跳过，确认不扩大范围、不清空备注。
5. 双端检查：窄屏不横滚整张表格，详情/导入弹层内容可滚动，手机键盘不遮保存区；关闭详情保留筛选/滚动/合理焦点，草稿切账号或离开提醒。两设备竞争保存应提示409冲突，不能静默覆盖。

账号删除会清除成就记录；有实质记录禁止修改游戏。涉及删除的人工验收仅使用用户自行准备的可丢弃账号。
