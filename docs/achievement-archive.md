# 成就档案：使用范围与人工验收

页面为 `/achievement`，沿用现有导航、网站登录和全站游戏账号；不需要羁绊助手。生产 feature flag 保持关闭，普通 Vite 开发可见。初始种子代号鸢0条、如鸢0条，实际目录由 MongoDB 已发布快照决定，管理员可在线维护。页面如实显示资料空缺，测试样例不会进入目录；有条目的真实使用验收需要已发布资料，组件测试不能替代真实资料验收。

## 功能与记录口径

主页面只显示“未完成 / 已完成”。历史 `completed` 对应已完成，`incomplete`、`pending` 及无记录均显示未完成，含义是“尚未标记完成”；仅浏览不会写回或批量改写历史数据。用户主动点击未完成时才提交明确的 `incomplete`。顶部仅有已收录成就、已完成、未完成、我的关注四项统计，按当前游戏有效目录计算；未完成 = 已收录 − 已完成，关注独立于完成状态，移出目录的历史记录不参与统计。

每行两态按钮和星标直接保存，成功才更新，保存中禁用重复提交；失败保持原值并在该行提示错误。状态仅提交状态，关注仅提交关注，不清空或填满数值进度、备注。未完成筛选中标记完成后，行内提示成功并提供撤销，停留6秒后移出结果；顶部统计立即按保存结果更新，筛选命中数在这6秒内包含待移出行。全页成功提示继续提供上一次操作撤销，恢复原始状态字段（包括历史 pending）及已知完成日期；不强制跳回页头。

列表最多50条，搜索名称/条件/实际关联密探名，保留游戏原生分类、奖励文本、两态、关注和隐藏属性组合筛选。奖励输入提供真实完整奖励文本建议，也可输入关键词；目录为空时不生成奖励类别。分类按目录顺序分组，分类头部显示整个分类的已完成数 / 有效目录总数，不随筛选改变统计口径。页面沿用常规模块的1180px容器上限，左右边距为桌面（≥1081px）48px、平板（768–1080px）32px、手机（≤767px）16px；列表占满该容器，不额外扩宽页面。桌面分为信息、奖励、进度、操作四区；普通行以约72px为布局基准，长条件自然增高。平板按可用容器重排，手机将信息和直接操作分层，不依赖横向滚动。页头统计、搜索和列表共用同一内容边距。

成就名称为普通标题，不打开详情。页面没有右侧详情区、详情弹窗、抽屉或独立详情页。完成条件直接显示；剧透保留在各行的“注意事项与剧透”折叠区，默认折叠。资料来源、别名、完成方法和章节不再展示或编辑，搜索不使用历史别名；旧目录 JSON 的 sources、aliases、method 和 chapter 字段仅保留格式兼容。

只有明确的数值类型及正目标显示数值编辑入口。个人进度未知时显示“进度未记录”，不伪造零或进度条；填写后显示数值 / 目标及细进度条。点击进度在当前行展开输入，允许非负合法数值、超目标值及对应口径小数；整数类型拒绝小数，留空保存为未知。保存、取消均在行内，不使用 prompt，达标不会自动完成。

行末备注图标展开当前行的个人备注，可查看、编辑、保存或取消；无备注且未展开时不占额外高度。既有可选实际完成日期保留在已完成条目的备注编辑区。进度和备注分别提交变更字段，保存一个不丢另一个草稿；完成日期草稿在两态切换后继续保留，回到已完成可保存，也可明确取消。取消脏草稿需确认，离开页面、刷新、切账号或进入导入前沿用未保存确认。筛选隐藏、分页、断点切换或目录读取失败不清空草稿；顶部“返回编辑”可回到仍在目录中的草稿所在页。账号上下文真正变化时清除旧草稿；迟到响应不能覆盖新账号。

后端保存后，在另一个设备进入页面、刷新或无脏草稿时重新激活读取，不实时推送、不离线假保存。revision 冲突重新读取并提示核对，脏草稿保留，可重试保存。两端复用同一控制器、权限和 API，CSS 分别持有布局。

“更多 → 导入与导出”继续备份当前账号全部原始记录，包括历史三态和移出目录的记录，不受筛选影响。格式仍为 YuanHub 成就 JSON v1，1000条/1MiB。选择文件自动预览，默认保留冲突，采用文件也不以空备注擦除已有备注。未知 ID 须明确跳过；非法项整批拒绝。预览后变更账号/文件/策略/版本需重新核对，预览10分钟失效或后端重启后重做。文件源账号仅提示，不能取得其它账号权限。

后台维护入口仍为 `/achievement/admin`，需要 `achievement_catalog:write`，独立于玩家功能开关。见 [成就目录管理](achievement-catalog-admin.md) 及后端 `BackEndV3-Share/docs/achievement-api.md`。本轮不修改后端、API、目录、路由、feature flag 或共享导航。

## 电脑和手机人工验收

复用正在运行的开发服务打开 `/achievement`。非浏览器组件检查不能证明真实布局、触控或软键盘表现；本轮没有启动、重启服务或执行浏览器自动化。

1. 桌面1440px：检查四项紧凑统计与搜索、全宽分组列表左右对齐；没有详情栏，标题不能打开详情。组合奖励、分类、状态和关注筛选，检查长条件自然换行。
2. 有真实条目时：在未完成筛选标记完成，统计更新、该行提示成功，可在6秒内撤销；等待移出后仍可用页头撤销。修改状态及关注后，确认个人进度和备注保持原值。
3. 有真实量化条目时：行内编辑进度与备注，分别保存、取消；未填进度不显示零。未保存备注时筛选隐藏/翻页，再“返回编辑”；离开/切账号应提醒，切换账号后不显示前一账号草稿。断网保存保留草稿，冲突提示核对最新内容。
4. 手机390px并补看320px，平板768px：检查筛选换行，状态、星标、备注及进度入口可达，无整页横滚或按钮重叠；展开输入后软键盘不妨碍滚动到保存/取消。缩放布局不应重建草稿或打开详情。
5. 少量明确选中后批量标记；导出并预览同一JSON，核对目标账号和历史三态兼容，预览不写入。真实跨设备保存、导入冲突和权限由用户独立验收。

账号删除会清除成就记录；有实质记录禁止修改游戏。涉及删除的人工验收仅使用用户自行准备的可丢弃账号。
