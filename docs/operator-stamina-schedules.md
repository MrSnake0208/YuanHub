# 体力日程的保存与回顾

体力规划沿用培养计划的本机存储范围，以子账号和培养计划分别隔离：

`yuanhub:cultivation-stamina-planner:v1:<accountId>:plan:<planId>`

尚未自定义日程时，推荐随当前库存和日期生成。用户首次修改任意一天的获取、支出或产出配置时，保存整个日程：库存与材料需求起点、培养目标、推荐配置、每日安排、结算结果及材料进度。外层存储版本仍为 1，新增可选的 `schedule` 字段；原有 `manualPlans` 保存每个自定义日期，旧版数据仍可读取。

- 刷新库存、真实日期变化或重新打开页面都不会自动改写已保存日程。清除某天的自定义安排后，完整日程仍保持固定。
- 已过日期以历史图标和「已过」标注，可查看当时保存的安排与预测；该标记不表示游戏内已完成。
- 计划预测与当前规划相关材料库存不同时显示差异，并提供「按当前库存更新」。比较以今天开始前的累计预测产出为基准；同一培养目标下的养成消耗按材料需求减少量扣除。
- 显式更新从今天的当前库存重新计算，保留过去日期的完整结算，以及今天和未来的自定义安排。清单或培养目标变化也会提示更新。
- 修改偏好或日程时，以计划保存的预测起点重算今天及之后，过去日期不变。编辑暂时造成体力超支时，后续已保存日期仍保留，预测产出暂停，修正后重新计算。
- 旧版过去的手工日期仅能恢复原安排，不能还原未记录的历史库存，界面会说明这一限制。

日期导航使用固定宽度的日期按钮，状态标记不改变布局。支持鼠标拖动、原生触屏滑动、前后一天按钮、方向键、Home / End 和回到今天；仅当选中日期被遮挡时，在日期栏内最小幅度滚动。不会将整个页面或已可见日期强制居中。

本机存储不是云同步，清除浏览器站点数据会移除保存的日程。功能入口继续遵守现有 `operatorGrowthTracking` 构建时开关。
