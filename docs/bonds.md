# 羁绊图鉴

玩家入口 `/bonds`，目录管理 `/bonds/admin`。复用本站账号切换、密探目录/头像/拥有状态及站点样式，不持久化第二套个人名单。玩家页面沿用现有构建期功能开关 `BOND_ARCHIVE`，当前只在Vite开发模式开放；这不是后端权限。正式开放与部署未执行。

## 使用

1. 今日查找选择行动、天气和成员搜索，查看一拍即合/貌合神离组合；公开目录无需登录。登录并选择现有游戏账号后可记录或取消，最多明确选择50条批量保存。
2. 完整图鉴按成员＋行动展开天气；桌面天气矩阵、手机换行布局共用数据和操作。搜索、拥有筛选、天气、隐藏已记录不会改变累计。未填写拥有资料时默认显示全部，不创建第二套拥有名单。
3. 备份迁移可导出当前账号完整 `yuanhub-bonds` schema_version=1 文件，包含历史记录。导入原生文件或旧助手JSON均须预览并确认；不会自动创建/同名关联账号。旧文件明确选择来源和目标，缺失游戏信息时必须选择；默认仅合并已记录项，false/缺项不清空。
4. 关联成就显示7档门槛，链接进入成就页按linked_metric筛选。自动进度来自同账号羁绊；人工完成状态独立，需要用户确认。取消不撤销已确认成就、不发放库存奖励。
5. 管理员用管理工作台「羁绊目录」维护：新增组合/天气或读取已授权转换文件，核对待处理数量，合入本地草稿，保存、预览发布并明确确认。修改成员/行动/天气必须新增身份；效果/状态可保留ID更正。未确认游戏可用性的资料不得发布。

累计包括当前和历史下架的已记录种数，误录不计数；当前图鉴比例另以active计。本站更新时间不代表游戏内首次触发。读取失败显示错误而非0%；保存只在服务器成功后更新状态，失败无“已保存”假象。409刷新当前档案并提示重试；管理编辑冲突保留本地草稿，可先导出再重新读取。

切换账号/退出立即清除旧档案，迟到请求不得回灌；保存/文件操作期间禁用切换。文件、来源、目标、游戏、策略、档案revision或目录版本变化均使预览失效。未知记录需明确跳过，非法/不匹配记录阻止整批。__missing__及外部游戏可用性覆盖不迁移到拥有资料。服务重启后预览需重做。

1. 刷新 `/bonds`，匿名切换游戏、选择天气、搜索密探，应显示目录且记录按钮要求登录；390px及1440px检查展开/点击和键盘焦点，补查320/430/768/1024px布局。
2. 登录选账号A，记录两个不同天气，累计增加2；反复设同状态不重复，取消一项减1。筛选/隐藏不改变累计，切B后无A记录，返回A仍正确。
3. 两个窗口编辑同一账号，后保存窗口出现版本冲突并刷新；模拟断网保存显示失败，不显示新“已记录”。读取失败与空目录/无结果应有不同提示。
4. 导出A备份，到同游戏测试账号B预览恢复并重复导入，数量不累加。旧文件选择来源/目标，缺游戏必须选择，unknown需确认跳过；更换目标后旧预览不能确认。
