# 羁绊图鉴

作者：线线&悠扬 · 独立创作。

玩家入口 `/bonds`，目录管理 `/bonds/admin`。复用本站账号切换、密探目录/头像/拥有状态及站点样式，不持久化第二套个人名单。玩家页面沿用现有构建期功能开关 `BOND_ARCHIVE`，开发与生产构建均开启，但入口、页面和后端接口必须具有 `archive:access`；暂仅平台管理员和超级管理员拥有，普通/内测用户及历史 `ARCHIVE_USER` 不放行。目录管理还需要 `bond_catalog:write`。部署未执行。

## 使用

1. 默认进入「图鉴收集」；「查找配对」整合原今日查找，进入时按晴天查询，支持全部天气及其他行动/天气条件。公开目录无需登录。可按密探名称、别名、拼音或缩写搜索；同时输入两个名称（空格或顿号分隔）查找指定配对。
2. 按密探独立展开/折叠，再按配对与羁绊效果显示实际天气条件。每张天气卡保留自己的行动，桌面约4～6列，手机2列；不补不存在的条件。同一条目可出现在多个密探下，收录共用 `bond_id`。密探进度按完整当前目录去重，不受筛选影响；顶部收集/羁缘统计沿用服务端 summary，「我的密探」按当前游戏的真实拥有资料统计，未读取时显示「—」。
3. 登录并选择账号后，直接点击天气卡切换收录，不弹详情。原「记录触发」就是布尔收录状态，不是次数累加；原「选择此天气」为批量勾选，移到「设置 → 批量选择天气」，最多50条。保存成功后同步所有副本、分组和顶部进度，失败不会伪造已收录。当前/历史资料、收录状态、行动、天气、效果、仅拥有、隐藏已收录继续可用；低频筛选在「展开筛选」。拥有筛选仍要求组合所有成员均拥有。未填写拥有资料时显示全部，不创建第二套名单。
4. 「设置 → 备份迁移」可导出当前账号完整 `yuanhub-bonds` schema_version=1 文件，包含历史记录。导入原生文件或旧助手JSON均须预览并确认；不会自动创建/同名关联账号。旧文件明确选择来源和目标，缺失游戏信息时必须选择；默认仅合并已记录项，false/缺项不清空。
5. 「图鉴说明」保留本站累计、目录版本和已发布羁缘目标说明，链接进入成就页按linked_metric筛选。自动进度来自同账号羁绊；人工完成状态独立，需要用户确认。取消不撤销已确认成就、不发放库存奖励。

管理员仍用管理工作台「羁绊目录」维护：新增组合/天气或读取已授权转换文件，核对待处理数量，合入本地草稿，保存、预览发布并明确确认。修改成员/行动/天气必须新增身份；效果/状态可保留ID更正。未确认游戏可用性的资料不得发布。

累计包括当前和历史下架的已记录种数，误录不计数；当前图鉴比例另以active计。本站更新时间不代表游戏内首次触发。读取失败显示错误而非0%；保存只在服务器成功后更新状态，失败无“已保存”假象。409刷新当前档案并提示重试；管理编辑冲突保留本地草稿，可先导出再重新读取。

切换账号/退出立即清除旧档案，迟到请求不得回灌；保存/文件操作期间禁用切换。文件、来源、目标、游戏、策略、档案revision或目录版本变化均使预览失效。未知记录需明确跳过，非法/不匹配记录阻止整批。__missing__及外部游戏可用性覆盖不迁移到拥有资料。服务重启后预览需重做。

## 数据维护边界

真实目录、待核实资料和导入结果仅保存在仓库外私有位置。生产目录由所有者手动导入数据库并发布；页面数量以当前已发布目录为准。资料使用须核实授权范围，本地导入授权不推定代码、素材及对外分发授权。

## 最小人工验收（未执行浏览器）

1. 打开 `/bonds`，默认图鉴收集；未授权账号不能进入；获授权账号可切游戏、搜索和展开密探，收录仍要求原有 Beta 资格和账号归属。「查找配对」显示今日查找和天气条件。390px及1440px检查分组、筛选、天气卡和键盘焦点，补查320/430/768/1024px及手机横屏，无整页横向溢出。
2. 登录选账号A，点击两个不同天气卡，顶部当前进度增加2；同条目在两名密探下同步，只累计一次，再点取消减1。筛选/隐藏不改变分组与顶部进度，切B后无A记录，返回A仍正确。设置中批量勾选同条目的两个副本，应只选择/保存一次。
3. 两个窗口编辑同一账号，后保存窗口出现版本冲突并刷新；模拟断网保存显示失败，不显示新“已记录”。读取失败与空目录/无结果应有不同提示。
4. 从「设置 → 备份迁移」导出A备份，到同游戏测试账号B预览恢复并重复导入，数量不累加。旧文件选择来源/目标，缺游戏必须选择，unknown需确认跳过；更换目标后旧预览不能确认。
5. 成就页筛选羁缘，进度只读；达标后手动确认，再取消羁绊，完成状态保留。管理员查看目录、改效果、保存草稿/预览；发布会修改公共目录，应仅在另有授权的测试环境手动操作。

非浏览器检查分别位于 `test/bonds.test.js`、`behavior/bonds.spec.js`、`behavior/bondsAdmin.spec.js` 及成就行为测试。实际结果见工作区任务验证记录；组件测试不能替代真实布局、触控和浏览器下载验收。

## 私有资料维护

羁绊目录只从数据库读取；所有者手动导入并发布，启动与部署不补资料。管理入口受部署端本人账号限制。羁缘目标来自目录响应 achievement_targets；未配置时显示资料尚未配置，不显示全部达标或固定门槛。真实组合、pending 与备份不得进入仓库或构建包。
